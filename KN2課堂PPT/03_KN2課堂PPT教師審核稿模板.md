# KN2 課堂 PPT 教師審核稿模板

> 執行順序與共用規格以根目錄 `製作契約.md` 為準；本文件保留 KN2／KN4 各自的課程與頁型內容。

本稿先核對課本內容、題目、答案、教學安排與教師決定，兩種輸出路線都適用。新課或內容變更先把核對結果整理到教材包的 `lessonPackage`、逐頁 `sources` 與 `items`，再按 editor UI 生成，或用可選的 `build_course.cjs` 批次生成 `.slides.json`；editor 只在生成後作可選微調。舊產生器路線才建立 `HTML_PPT製作稿`。符合 `頁碼`、`檔名`、`投影片畫面文字` 欄位的 Markdown 匯入 editor 只建立保留全部列的待溯源文字草稿，不重建舊版面、圖片或互動，未完成來源與核對前不得正式放映或匯出。

## 四項排版審核基準

0. 共用主要內容區左右內距：所有頁型的主要內容區距投影片左、右邊界各 `27px`；頁型專屬卡片與頁尾資訊不得超出此安全區。

1. 段落間距：例句與例句、題目段落與題目段落之間 `6px`；AB 對話為同一例句區塊。
2. 同一句換行：無超綱 `line-height: 44px`；含超綱且可能換行或實際換行，外層 `60px`、超綱詞內部 `42px`。
3. 超綱標注：inline；拼音上、越南語下，兩者 `9.33px`；拼音距離 `-5px`、越南語距離 `-4px`；漢字同基準線／同視覺高度。
4. 編號例句：`1.`、`2.` 等標號需獨立成標號欄，句子獨立成句子欄；句子換行時第二行對齊句子欄第一個漢字，不對齊標號。
