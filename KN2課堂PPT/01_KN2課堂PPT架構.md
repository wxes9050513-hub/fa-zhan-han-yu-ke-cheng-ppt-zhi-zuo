# KN2 課堂 PPT 架構

> 執行順序與共用規格以根目錄 `製作契約.md` 為準；本文件保留 KN2／KN4 各自的課程與頁型內容。

本架構適用於 KN2 HTML 課堂投影片。每課暫以 45 分鐘 x 3 堂，共 135 分鐘規劃；若實際排課不同，依「必上環節」優先保留，刪減備用練習與延伸任務。

KN2 是初級到準中級銜接課程。課堂不追求長篇發表，重點是：學生能聽懂問題、用提示句型回答、用本課生詞完成短句或短對話。

HTML 視覺與互動樣式可參照 KN4 成品：固定 960 x 540 投影片、上方頁型 Banner、左下課本來源、右下頁碼、翻牌與點擊答案互動、任務頁 QR Code 留白。所有頁型只要出現中文例句，都需套用漢字對齊規則；一般漢字與超綱標注漢字需保持同一基準線／同一視覺高度。最後一頁固定放本課回家作業與下一課課前預習 Formative Link／QR Code；學生頁課號格式用 `KN2 - L1`、`KN2 - L2`，下一課入口不加中文課名；頁內標題固定用 `下课`，不用 `Bài tập về nhà` 作大標題；兩個入口字卡標籤需用不同標色。尚無實際連結時 PPT 只保留 QR Code 空框，不顯示 `Link` 待補文字，不放假連結。KN2 頁面順序與教學難度仍依本架構，不套用 KN4 課程架構、學生程度或活動數量。

## 全課固定環節

課文處理採「段落循環」：依每課實際課文／對話段數，逐段完成「預習回收 → 該段核心生詞講解 → 該段語法／句型講解 → 對應語法練習」。不預設一定三段課文；但每一段課文都必須完成一輪後，才進入功能句說明與練習、口語任務與收尾。

| 順序 | 環節 | 設計原則 |
|---|---|---|
| 1 | 封面 | 2 分鐘，帶課名、主題與生活情境；課名儘量單行呈現，除非過長。 |
| 2 | 暖身活動 | 只設計一個活動，可為看圖說話或回答問題；問題需短、明確、可用本課主題回答；`Từ gợi ý` 提示詞若超出本課已教範圍，需做超綱生詞標記；若同時有原因／感受詞，可與 `Từ gợi ý` 合併同一區塊但用兩色區分。 |
| 3 | 預習回收 | 依課本「课文」或課前預習問題回收；一題一頁，正面問題、背面完整句參考答案。 |
| 4 | 生詞講解 | 不做生詞總覽；AI 先選核心生詞。1 頁一個詞為主；合併詞限同詞族、同器物補充或教師明確要求。若一詞同時有動詞／名詞用法，例句需各放一句。若生詞已作為「大声读一读」語法／句型主項講解，生詞頁不再重複講。 |
| 5 | 語法／句型講解 | 以課本「大声读一读」中的語法／句型為主；每頁必須有句型說明，包含句型公式與用法；句型公式可用中文，情境／用法說明必須用越南語；一般語法頁由上至下排列 `Cách dùng`、`VD1`、`VD2`、`VD3`，每組標籤獨立一行、內容放下一行，不做成左標題右內容兩欄；若有兩個並列結構或 `vs`／比較型語法，使用「文法特殊頁 - 雙區塊」；若同一語法有三個並列結構，可使用「文法特殊頁 - 三區塊」；例句短而可套用。 |
| 6 | 語法／句型練習 | 一個語法一組練習（可依容量拆成連續頁），緊接在講解頁後；每組拆頁前預設 3-5 題（續頁可少於 3 題）；題型固定從「給情境造句、用語法完成句子、用語法完成對話」中選一種為主，同一練習頁不混用多種題型。 |
| 7 | 功能句說明 | 以課本功能句為主；一頁只放一個功能項目；功能句練習題數儘量等同該功能項目的目標句數。 |
| 8 | 口語任務 | 兩人一組，完成課本口語練習或交際任務；全班課堂內錄 Formative。 |
| 9 | 上台演練 | 每課抽或指定 5 組，每組短演練；老師只修共通錯誤。 |
| 10 | 收尾與作業 | 1 分鐘提醒本課回家作業與下一課課前預習 Formative Link／QR Code；尚無連結時 PPT 只保留 QR Code 空框。 |

## KN2 頁數與時間建議

| 堂次 | 建議內容 | 預估時間 |
|---|---|---:|
| 第 1 堂 | 封面、暖身、第一段課文／第一組對話循環：預習回收、核心生詞、句型與練習 | 45 分 |
| 第 2 堂 | 下一段課文／下一組對話循環：預習回收、核心生詞、句型與練習 | 45 分 |
| 第 3 堂 | 完成剩餘課文段落循環後，再進功能句、口語任務、Formative 錄音、5 組演練、收尾 | 45 分 |

## KN2 頁面配置建議

| 建議頁碼範圍 | 環節 | 頁面要做什麼 |
|---|---|---|
| P1 | 封面 | 放 `KN2 - Bài {{lesson_number}}` 與課名；不放總時長；課名儘量單行呈現。 |
| P2 | 暖身 | 一個中文簡體問題，搭配越南語 Banner `Khởi động`、提示句型與提示生詞；提示詞需依超綱詞格式加拼音與越南語。 |
| 課文段落循環 | 預習回收 → 生詞講解 → 語法／句型 → 語法練習 | 依課本實際課文／對話段數逐段安排；每段先做該段預習回收，一題一頁；接該段核心生詞；再接該段「大声读一读」語法／句型與對應練習。每一段都完成此輪，才進入功能句。 |
| 功能句／口語任務 | 功能句說明頁 + 功能句練習頁 + 口語任務 | 不插入未完成的課文段落循環中；功能句說明頁一頁只放一個功能項目，不同功能需拆頁；左側功能名稱使用越南語；功能句練習題數儘量等同該功能項目的目標句數；口語任務合併說明、準備、Formative 錄音與上台要求；預留 QR Code。 |
| 最後一頁 | 收尾與作業 | 放本課回家作業與下一課課前預習兩個 Formative Link／QR Code 區塊；任何 link 產生 QR Code 或放入 PPT 前，必須先開啟確認 Formative 標題、課次與作業類型；本課課前預習 link 不放入同課 PPT；頁內標題固定用 `下课`；課號格式用 `KN2 - L{{lesson}}`，下一課入口不加中文課名；不用 `Bài tập về nhà` 作大標題；兩個入口字卡標籤用不同標色；1 分鐘帶過；尚無連結時 PPT 只保留 QR Code 空框。 |

## 團體任務規則

| 項目 | 規則 |
|---|---|
| 班級人數 | 預設 40 人，可依實際班級調整。 |
| 分組 | 兩人一組，共約 20 組。 |
| 錄音 | 全班都在課堂上完成 Formative 錄音，不要求回家補錄。 |
| 上台 | 每課抽或指定 5 組。 |
| 上台組 | 也必須完成 Formative 錄音。 |
| 未上台組 | 以 Formative 錄音作為課堂產出。 |
| 任務難度 | KN2 任務以 4-6 句短對話為主，除非課本任務要求更長。 |

## KN2 低年級適配原則

| 項目 | KN2 做法 |
|---|---|
| 問題 | 短問題優先；若問題較長，拆成兩句或改成 AB 對話。 |
| 提示 | 預習回收與暖身盡量給提示句型；提示生詞需有拼音與越南語；暖身 `Từ gợi ý` 若屬學生尚未學過的詞，一律按超綱生詞格式呈現；暖身原因／感受詞可與提示詞合併同區但保留色彩區分。 |
| 生詞 | 優先講生活場景中能立即使用的詞；抽象詞少講、用短例句；一頁一詞為主，非同詞族或非器物補充不要硬合併；同一詞若有動詞／名詞兩種高頻用法，例句各放一句；若與「大声读一读」語法／句型重複，刪掉生詞講解頁，改在語法頁處理；不另設生詞小練習。 |
| 語法 | 以課本「大声读一读」為主要依據；每個語法講解頁必須有句型說明，包含句型公式與用法；句型公式可用中文，情境／用法說明必須用越南語；說明使用情境即可，不做長篇語法分析；一般語法頁直向排列，先放 `Cách dùng`，再依序放 `VD1`、`VD2`、`VD3`；每組標籤獨立一行、內容放下一行，不做成左標題右內容兩欄；兩個並列結構或 `vs`／比較型語法使用「文法特殊頁 - 雙區塊」；若同一語法有三個並列結構，可使用「文法特殊頁 - 三區塊」。 |
| 練習 | 語法練習固定採三類且每組拆頁前預設 3-5 題（續頁可少於 3 題）：給越南語情境後讓學生用目標語法造句、給提示生詞庫完成句子、用目標語法完成 AB 對話；同一練習頁以一種題型為主，避免混用；提示詞庫只放需要選用的詞，若目標語法固定附加詞如 `好好儿`，提示詞庫只放動詞；練習題需避開前一頁例句的原句重複或高度相似題；功能句練習題數儘量等同該功能項目的目標句數；避免直接重複回家作業題。 |
| 輸出 | 以一句話回答、兩句補充、4-6 句對話為主。 |
