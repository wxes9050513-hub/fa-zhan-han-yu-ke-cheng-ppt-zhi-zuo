# KN2 課堂 PPT 製作流程

> 執行順序與共用規格以根目錄 `製作契約.md` 為準；本文件保留 KN2／KN4 各自的課程與頁型內容。

本流程用於製作 KN2 HTML 課堂投影片。新課或內容變更固定先讀課本，在 editor 教材資料庫建立／更新教材包與結構化 `items`，完成來源與教師內容核對後按 UI 生成，或以可選的 `scripts/build_course.cjs` 生成 `.slides.json`；生成後才可用本倉庫根目錄 `index.html` 的 editor 作可選手動微調。既有舊課仍可沿用朋友本機的 `ai-teaching-material-system-main` 舊產生器；兩條輸出路線的共同內容規則以根目錄 `製作契約.md` 為準。

`scripts/prepare_lesson_package.py` 可整理文字檔與有文字層的原生 PDF；掃描 PDF 沒有文字時需先取得 OCR，不能臆造內容。教材包寫入 `lessonPackage`、逐頁 `sources` 與 `items`；AI／教師整理不等於教師核可，程式結構檢查也不取代語意與程度判定。符合 `頁碼`、`檔名`、`投影片畫面文字` 欄位的 `HTML_PPT製作稿` 匯入 editor 只作保留全部列的待溯源文字草稿，不會重建舊版面、圖片配置、互動或答案；未完成來源與核對前不得正式放映或匯出。舊產生器路線才需要 HTML_PPT 製作表、Manifest 與舊 presenter 檢查。

## 六項通用排版規則

**共用主要內容區左右內距**：所有頁型均以 `960 x 540` 為投影片畫布，主要內容區距投影片左、右邊界各 `27px`；頁型專屬卡片、來源與頁碼仍須在此安全區內另行排版。

1. **段落間距**：例句與例句、題目段落與題目段落之間使用 `6px`；AB 對話視為同一個例句區塊，不拆成多個獨立排版容器。
2. **同一句內部自動換行**：無超綱標注使用 `line-height: 44px`；含超綱標注且可能換行或實際換行時，外層文字區塊使用 `line-height: 60px`，超綱詞內部行盒固定 `line-height: 42px`。
3. **超綱生詞標注**：使用 inline 格式，拼音在漢字上方、越南語在漢字下方；拼音與越南語字級皆為 `9.33px`，拼音相對漢字的排版偏移參考 `-5px`、越南語相對漢字的排版偏移參考 `-4px`；一般漢字與超綱漢字需同基準線／同視覺高度。
4. **編號例句換行對齊**：`1.`、`2.` 等標號需獨立成標號欄，句子獨立成句子欄；句子換行時第二行對齊句子欄第一個漢字，不對齊標號。
5. **練習頁容量與拆頁**：練習頁若實際渲染後超出 PPT 安全區，永遠優先依題目順序拆成兩頁或多頁；不得先以縮小字體、壓縮行距、縮短題目或刪減答案槽硬塞同一頁。
6. **HTML presenter 狀態保留（舊產生器路線）**：`index.html` 需用 `#slide-XX` 保留目前頁碼；重新整理後主投影片需停留在同一頁，左側 `Mục lục` 縮圖側欄也需自動捲動到目前 active 頁縮圖所在位置，不可跳回第一頁。editor 路線依 `.slides.json` 的固定頁面 ID 與匯出 HTML 的頁面位置保存狀態。

**排版修改後複檢**：每次調整 PPT 排版後，必須重新檢查該頁是否符合通用格式標準，不可只檢查剛修改的局部。通用格式標準至少包含：960 x 540 安全區、主要內容區左右各 `27px` 內距、上方 Banner、左下來源、右下頁碼、段落間距、同一句內部自動換行、超綱生詞格式與漢字對齊、題目／例句換行對齊、該頁型專屬版面規則；練習頁若超出，仍優先拆頁。

## 1. 建立課程資料夾

1. 在 `KN2課堂PPT` 中找到或建立對應課次子資料夾。
2. 每課子資料夾建議放：
   - `{{lesson}}課堂PPT架構.md`
   - `{{lesson}}課堂PPT教師審核稿.md`
   - `{{lesson}}HTML_PPT製作稿.md`（舊產生器路線）
   - `{{lesson}}.slides.json`（教材包生成後的 editor 路線）
   - `素材整理/`
   - `HTML輸出連結.md`

## 3. 整理課堂架構

依 `01_KN2課堂PPT架構.md` 建立該課完整頁面表。

必須包含：

- 封面，2 分鐘；課名儘量單行呈現。
- 一個暖身活動；`Từ gợi ý` 提示詞若未先教過，需做超綱生詞標記；原因／感受詞可與 `Từ gợi ý` 合併同一區，但需保留色彩區分。
- 課文處理採「段落循環」：依每課實際課文／對話段數，逐段完成「預習回收 → 該段核心生詞講解 → 該段語法／句型講解 → 對應語法練習」。不預設一定三段課文；每一段課文都完成一輪後，才接功能句學習、口語任務與收尾。
- 預習回收：一題一頁，答案為完整句，問題卡與可選提示區需留在 PPT 安全區內；若教師指定刪除提示，該頁不得出現 `Từ gợi ý` 或 `Mẫu câu`。課文資訊、問題閃卡、`Mẫu câu`、`Từ gợi ý` 依序放入同一個主內容區，主內容區可定位，但內部區塊採垂直正常流程，不個別固定定位；P05 型間距依序為 `12px`、`4px`、`7px`，並保留底部來源與頁碼安全區。
- 生詞直接講解，不做總覽頁。
- 核心生詞頁依教師指定增刪；刪除的生詞若仍在課文原文、語法例句或功能句中出現，可保留原句，不再新增講解頁。
- 不做生詞小練習。
- 語法／句型講解以課本「大声读一读」中的語法／句型為主，並搭配固定題型的語法練習。
- 功能句學習與功能句練習按課本功能項目設計，練習題數儘量對齊該項目的目標句數；不同功能項目若拆成不同學習頁，練習也分頁。
- 口語任務：課堂準備、課堂 Formative 錄音、抽 5 組上台。
- 課本「词语扩展任务」若加入，只放在口語任務主活動後作 `MỞ RỘNG`；一頁一個課本指定目標詞，課本已給完整答案的示例詞不放入學生頁，也不作角色扮演答案詞庫。
- 收尾與作業提醒，1 分鐘。

## 4. 選生詞

AI 先判斷哪些生詞需要課堂特別講解。

選詞原則：

- 影響課文理解。
- 影響口說輸出。
- 學生容易誤用。
- 可用於生活情境。
- 能搭配本課功能句或口語任務。
- 未被選為「大声读一读」語法／句型主項。

頁面原則：

- KN2 原則上 1 頁一個生詞；合併詞只限同詞族、同器物補充或教師明確要求。
- 核心生詞頁依教師指定增刪；被刪除的生詞若仍出現在課文原文、語法例句或功能句中，只作原文保留，不再當核心生詞頁處理。
- 同一生詞若有動詞／名詞等高頻用法，例句各放一句。
- 若生詞同時是課本「大声读一读」的語法／句型主項，刪掉生詞講解頁，改放在語法／句型頁講解。
- 不安排生詞小練習頁；生詞使用能力改由語法練習、功能句練習與口語任務檢查。
- 每頁包含漢字、拼音、越南語詞性與越文。
- 若一頁有 2-3 個生詞，改用頁型 D-2：將左側生詞區拆成單欄垂直排列的 2 或 3 張等寬、等高獨立閃卡；2 個生詞上下兩張，3 個生詞上中下三張，不得拆成左右分欄。每張卡各自提供正面拼音＋漢字、背面越南語詞性＋越南語翻譯，並各自具備獨立翻牌動畫。只有 1 個生詞時沿用一般單卡。
- 生詞、拼音或越南語過長時，單卡先優先縮小漢字；縮小後仍無法容納，才在自己的文字區塊內換行。此規則同時適用單卡、雙卡、三卡正反面；不得超出卡片、造成重疊、改變其他卡片尺寸或破壞右側例句版面。
- 生詞頁左側白色生詞框做成閃卡，正面以拼音＋漢字為主，背面只放兩行：越南語詞性在上、越南語翻譯在下；不顯示 `Loại từ`、`Nghĩa` 等欄位標籤。詞性用青綠色 `#5AACAC`，翻譯用深藍色 `#1A3A5A`，兩行水平、垂直置中，間距約 `6px`。離合詞可在正面漢字下方加紫色越南語提示 `Động từ ly hợp`，成語可加 `Thành ngữ`；兩者不放在背面。
- 生詞頁詞性必須使用越南語，例如 `động từ`、`danh từ`、`tính từ`；背面不得改回中文詞性或新增欄位標籤。
- 製作與 QA 時，必須確認背面只有越南語詞性與越南語翻譯兩行，顏色、置中與上下間距符合規格；離合動詞／成語標注仍只檢查正面漢字下方。
- 生詞頁右側互動問句或例句統一標為 `Mẫu câu`。
- 生詞頁若補充句型結構，標籤統一用 `Cấu trúc`。
- 例句中的本頁生詞需用黃底紅字突出。
- 例句儘量使用問句或短 AB 對話。
- 第一層：段落間距。所有頁型中，例句與例句之間、題目段落與題目段落之間統一用 `6px`；適用於生詞例句、語法／句型例句、功能句例句、練習題段落與 MỞ RỘNG 例句。AB 對話視為同一個例句區塊，不拆成多個獨立排版容器；A/B 換行不靠段落間距控制，改由第二層 `line-height` 控制。
- 第二層：同一句內部自動換行。單一句子、單一題目或同一組 AB 對話若在同一區塊內自動換行，用 `line-height` 控制行距。無超綱標注時以 `line-height: 44px` 為基準；含超綱標注且可能換行或實際換行時，外層文字區塊用 `line-height: 60px`，超綱詞內部行盒固定 `line-height: 42px`，並保留拼音相對漢字的排版偏移參考 `-5px`、越南語相對漢字的排版偏移參考 `-4px`，避免上行越南語與下行拼音重疊。
- 練習頁若實際渲染後超出投影片安全區、頁尾來源或頁碼區，第一方案永遠是依題目順序拆成兩頁或多頁；不可優先用縮小字體、壓縮行距、縮短題目或刪減答案槽硬塞同一頁。字級微調只能作為拆頁後的細部排版。拆頁後需同步更新檔名、頁碼、總頁數、Manifest、縮圖與對應製作稿／審核稿。
- 編號例句、編號題目或功能句例組若使用 `1.`、`2.`、`3.` 等標號，需拆成「標號欄＋句子欄」；標號欄固定於左側，句子欄從第一個漢字開始。句子自動換行時，第二行對齊句子欄第一個漢字，不對齊標號；若句中有超綱標注，仍同時套用漢字對齊、超綱標注與第二層 `line-height` 規則。
- 生詞頁右側例句採固定排版基準：右側卡片左內距 `10px`、右內距 `10px`、卡片寬度 `546px`、文字可用寬度 `526px`、卡片右側邊界到投影片邊界 `27px`、右側卡片左側邊界到左側卡片右側邊界 `10px`；例句主字級 `22pt`、一般同句換行 `line-height: 44px`、段落間距依第一層通用規則用 `6px`；含超綱標注且可能換行或實際換行時，依第二層規則使用外層 `line-height: 60px`、超綱詞內部 `line-height: 42px`；超綱標注的拼音與越南語字級 `9.33px`；拼音相對漢字的排版偏移參考 `-5px`，越南語相對漢字的排版偏移參考 `-4px`；以 `22pt` + Noto Sans SC 渲染後，漢字高度以未縮放畫布的實際字形為準，`42px` 僅為超綱詞內部行盒高度。以上需用截圖或 DOM 字框量測，不只看 CSS 屬性。
- AB 例句整體只放在一個獨立內容區塊內，不拆成多個 `content-card` 或多個獨立排版容器；A/B 可分行或自然換行，但同一段對話需共用同一組字級、段落間距與第二層 `line-height` 規則。
- 超綱詞使用上方拼音、下方越南語的 inline 標記時，排版需以漢字基線為主，拼音與越文標注不得改變超綱漢字和一般漢字的高度對齊；含超綱 inline 標記的例句或練習句需避免拼音、越文標注碰到上一行文字。
- 圖片不是必須，但可用 icon 或小圖輔助具體詞、動作詞與生活場景詞。
- 生詞頁補圖不是預設必做；HTML_PPT 製作稿定稿後、圖片生成前，先檢查每個候選生詞頁的右側例句或 AB 對話下方空間。可用高度約 `140px` 以上才可考慮約 `180px x 110px` 小圖；約 `90px` 到 `120px` 原則上不補，除非教師指定。優先補具體名詞、具體物品、明確動作或生活／校園場景詞；抽象詞、語法性強的詞、功能詞或例句已足夠清楚者不優先補。不得為補圖縮小例句、壓縮行距、破壞超綱標注或造成例句不必要換行。

## 5. 整理預習回收

每題一頁。

每頁必放：

- 課本問題或課前預習問題。
- 課文資訊：`课文：P{{page_range}}《{{text_title}}》`。
- 參考答案，放在閃卡背面；必須是完整中文句子。
- 閃卡背面答案文字水平左對齊、垂直置中；無超綱標注時換行使用 `line-height: 44px`；含超綱標注且可能換行時，外層使用 `line-height: 60px`、超綱詞內部使用 `line-height: 42px`。
- 教師備註。

KN2 原則：

- 問題短化、支架明確化。
- 提示生詞與提示句型是可選支架；若教師指定刪除提示區，畫面只保留題目、課文資訊與背面答案，不顯示 `Từ gợi ý` 或 `Mẫu câu`。
- 問題卡、提示句型、提示詞與答案卡不得超出 PPT 安全區，也不得壓到底部來源與頁碼。
- 可用 `你呢？`、`你觉得呢？`、`你想不想……？` 做延伸，但不要一次放太多追問。
- 若答案超出學生程度，改成更短、可仿說的完整句。
- 製作時先建立預習回收主內容區，再依序放置課文資訊、問題閃卡、`Mẫu câu`、`Từ gợi ý`；提示內容變多時讓正常流程推動下方區塊，不能用個別絕對定位硬塞進閃卡區。完成後以 DOM 或截圖確認四區塊的順序、`12px`／`4px`／`7px` 間距，以及與來源文字、頁碼的安全距離。

## 6. 整理語法與句型

先從課本「大声读一读」選語法／句型主項。若其中項目和生詞重複，刪掉對應生詞講解頁，避免同一詞重複講兩次。

每個語法至少包含：

- 句型說明，包含句型公式與用法；句型公式可用中文，情境／用法說明必須用越南語。
- 使用情境，必須用越南語說明。
- 課本「大声读一读」例句，必要時補課文例句。
- 補充短例句或一組 AB 對話。
- 一般語法講解頁採直向排列：先放 `Cách dùng` 說明，再放 `VD1`、`VD2`、`VD3` 或一組 `Hội thoại`；每組標籤獨立一行、內容放下一行，不做成左標題右內容兩欄。
- 若同一語法有兩個並列結構、兩種用法，或 `A vs B` 比較型語法，使用「文法特殊頁 - 雙區塊」取代原本的 `vs` 特殊左右比較頁：上方主句型大卡置中，下方兩個等寬白底區塊；每格最上方放結構／比較項並使用不同標色，標題置中，說明、`VD` 與例句依序排列，例句置左，兩格內部高度一致。
- 若同一語法有三個並列結構，可使用「文法特殊頁 - 三區塊」：上方主句型大卡、其下 `Cách dùng`、下方三個等寬白底區塊；每格最上方放結構並使用不同標色，結構置中，`VD` 與例句置左，三格內部高度一致。
- 雙區塊或三區塊頁若使用編號例句，各區塊需同步使用「標號欄＋句子欄」；句子換行時對齊句子欄第一個漢字，不對齊 `1.`／`2.` 等標號。
- 一組固定題型語法練習，每組拆頁前預設 3-5 題（續頁可少於 3 題）；同一頁以一種題型為主，不混用兩種以上題型。
- 語法頁所有中文例句都必須套用漢字對齊規則；若例句含超綱 inline 標注，一般漢字與超綱漢字需保持同一基準線／同一視覺高度，拼音與越文標注不得撐高或壓低該行漢字。
- 例句中的本課語法內容用黃底紅字突出。
- 若語法頁列多個疑問詞／句型例組，每個例組下方加越南語；可固定顯示中文例組，只讓越南語翻譯由左至右點擊彈入。

練習題規則：

- 先檢查回家作業，已用題目不要直接重複。
- 一個語法一組練習（可依容量拆成連續頁），並緊接對應語法講解頁。
- 語法練習需留在所屬課文／對話段落循環內，不提前挪到所有課文回收後，也不跨段合併成總練習；教師明確指定綜合練習時除外。
- 每組拆頁前預設 3-5 題（續頁可少於 3 題）。
- 製作練習頁前先判斷頁型：G4 情境造句、G5 完成句子、G6 完成對話、G7 判斷填空；問答翻牌用 G1，圖片造句用 G2，圖片閃卡用 G3。同一頁以一種題型為主。
- 提示詞庫只放需要選用或替換的詞；若目標語法本身固定帶入某詞（如 `好好儿`），提示詞庫只放動詞或內容詞，不重複放目標語法詞。
- 自製或改寫題需避開前一頁語法例句與課本課文原句的重複或高度相似題；不可只替換少量詞語、人物、時間或數字。可練同一語法結構，但情境、詞彙、動作或句意需明顯不同。
- 完成對話題的答案需是完整中文句子，不只填入語法片段；不同題目段落需遵守第一層段落間距 `6px`，同一組 AB 對話內部換行需遵守第二層 `line-height` 規則。
- 練習頁的頁內文字說明只放 1-2 句越南語操作指令，文字使用綠色 `#5AACAC`；不放 `Cách làm`、語法名稱、句型名稱或額外語法說明。
- G4 情境造句：給越南語情境，讓學生用目標語法造完整中文句；情境要清楚引導語法，答案槽可另起一行，底線需固定長度且可略偏長；中文答案用點擊紅字帶入。
- 情境造句例：語法 `好 + adj.`，題目 `Bạn đang ăn 1 tô phở, bạn cảm thấy rất ngon, bạn nói: _________。`，答案 `这碗河粉好好吃。`
- G5 完成句子：給中文句子或提示詞庫，讓學生補入目標語法、句型或詞語；提示詞庫只放需選用或替換的詞。
- 完成句子例：語法 `好 + adj.`，提示詞庫 `好吃、好喝、好玩`，題目 `这碗河粉________。`，答案 `好好吃。`
- G6 完成對話：用目標語法完成 AB 對話；`A:` 與 `B:` 必須分行；同一組 AB 對話不拆成多個獨立排版容器；答案需是完整中文句子。
- 完成對話例：語法 `刚 + V`，題目 `A：你到家了吗？ B：________。`，答案 `我刚到家。`
- G7 判斷填空：用於判斷該填哪個結構、詞語或是否不需填入；若無需填入，用 `X`；題目需讓學生能判斷語境差異。
- 練習頁內不重複 `Luyện tập`；改放 1-2 句綠色越南語操作指令。
- 若練習改為「問答」型，使用「練習頁 - 問答」：頁面只放 1-2 句綠色越南語操作指令，不放 `Cách làm`、語法名稱標籤或額外語法說明；題目由上至下排列，一行一題；每題做成獨立翻牌卡，正面題號＋問句，背面完整句答案，點同一卡可翻回；目標語法／句型在答案中用黃底紅字突出。
- 若練習改為「圖片閃卡」型，使用「練習頁 - 圖片閃卡」：頁面只放 1-2 句綠色越南語操作指令；建議 4 題；正面為圖片＋題號，背面為完整中文答案；預設四卡橫向排列，若圖片細節多或答案較長可改 2x2；圖片需清楚對應答案情境，圖片內文字、字母、數字或字幕依教師指定與圖片需求表；目標語法／句型在答案中用黃底紅字突出；單頁 HTML 與 `index.html` presenter 都需可直接點擊卡片翻面／翻回。
- 填空答案用點擊動畫以紅字帶入空格。
- 題號統一做成綠底綠字題號標籤；若同一組練習因版面拆成多頁，後頁題號需承接前頁，不可重新從 1 開始；換行需對齊句子首字；練習頁底部需留出來源與頁碼安全區。
- 非疑問句以 `吧` 結尾時，句末使用 `！`。

## 7. 整理功能句

功能句採兩頁結構：

1. 功能句說明頁：一頁只放一個功能項目。左側白卡放 `Chức năng` 與功能名稱，KN2 功能名稱使用越南語；兩者垂直置中，`gap`／`margin-top` 以 `6px` 為基準；功能名稱字級以 `30px` 為基準，需單行呈現，若字體過大需自動縮小到不換行且不超出白框。右側白卡標籤統一用 `MẪU CÂU`，標籤下方只放該功能對應的課本功能句或教師指定功能句；閃卡正面或投影片可見正面不放 `Dùng khi...` 使用情境說明。不同功能不可同頁混放，若同課有多個功能，需拆成不同功能句說明頁。製作教師審核稿時，必須先確認並標出本頁可套用的句型／語塊重點；未確認前不得進入 HTML_PPT 製作稿或 HTML PPT 製作。
2. 功能句練習頁：以課本功能項目練習為主，頁內文字說明用 1-2 句綠色越南語操作指令，例如 `Hoàn thành hội thoại.`，題目前放 `Tình huống（n）：` 情境列。若為自製或教師要求重寫，需根據前一功能句說明頁已標出的句型／語塊設計新情境，不可只把前頁功能句例句挖空後填回答案。

KN2 原則：

- 功能句例句要短，必要時只保留最常用句。
- 不同功能不可混在同一功能名下，例如 `吃惊、意外` 與 `请求、要求` 需分開呈現。
- 不同功能若分頁學習，練習頁也分開；例如 `吃惊、意外` 的練習不放入 `请求、要求` 練習頁。
- 功能句練習題數儘量等同該功能項目的目標句數；原則上每題對應 1 個目標功能句。
- 練習情境需清楚，學生看得懂誰跟誰說話。
- 功能句說明頁標出的句型／語塊需能遷移到新情境，例如 `我建议你 + 建议内容`、`我看你还是……吧！`、`N 是……`、`N 的意思是……`、`……也不错`、`挺……的`；不可只標固定詞。
- 自製或教師要求重寫的功能句練習需創造不同情境，練習前一說明頁標出的句型／語塊；避免與前頁功能句例句或課文原句高度相似，不只替換人物、時間、地點或少量詞語。
- 若一頁太擠，拆成一題一頁。

若任何頁面完成實際渲染後超出投影片安全區、頁尾來源或頁碼區，必須拆頁保留完整內容，不得以過度縮小或刪減內容處理。拆頁時維持原題目／例句順序，並同步更新後續 HTML 檔名、Manifest／縮圖清單、總頁數、頁碼、教師審核稿與 HTML_PPT 製作稿；拆頁後需重新檢查新頁與所有順延頁。

## 10. 製作 HTML_PPT 製作稿（僅舊產生器路線）

舊產生器路線在教師審核稿通過後，建立 `{{lesson}}HTML_PPT製作稿.md`，再製作 HTML。新課或內容變更的 editor 路線不以本稿作為正式來源，而是先建立並核對教材包的 `lessonPackage`、逐頁 `sources` 與 `items`，再按 UI 生成 `.slides.json`，或使用可選的 `build_course.cjs` 批次生成。若要匯入舊稿，檔案必須含 `頁碼`、`檔名`、`投影片畫面文字` 欄，匯入後只建立保留全部列的待溯源文字草稿，不能繞過來源、答案、指令或核對。

製作稿用途：

- 固定已通過的頁碼、堂次、時間與活動順序。
- 將每頁轉成 HTML 製作欄位：檔名、頁型、畫面主標、投影片畫面文字、互動／動畫／素材、教師備註。
- 確認投影片畫面上的說明文字是越南語，中文內容是簡體中文。
- 標明圖片、icon、點擊答案、動畫或 Formative 規則。
- 標明頁型版式：上方 Banner、頁型 icon／字標、左下來源、右下頁碼、翻牌、點擊答案、QR Code 留白；最後頁需標明本課回家作業與下一課課前預習 Link／QR Code 狀態，並確認每個 link 已開啟檢查內容與擺放位置、頁內標題為 `下课`、上方 Banner 為勾勾 icon + `下课`、不加下一課中文課名、不用 `Bài tập về nhà` 作大標題、兩個入口字卡標籤不同標色。
- 功能句說明頁需在製作稿中標明可套用的句型／語塊重點；自製或教師要求重寫的功能句練習需在教師備註中標明對應前一說明頁哪一個重點。
- 教師備註只放製作稿或 presenter notes，不放進學生畫面。
- 若本課要使用 ChatGPT 生成圖片，需依 `05_KN2圖片生成與嵌入流程.md` 在 HTML_PPT 製作稿中新增圖片需求表與 prompt。封面圖可單獨生成；生詞、圖片造句、功能句或情境任務圖可整理成 contact sheet 批次。HTML/CSS 畫出的視覺元素、暫用 SVG、placeholder 圖與生詞頁可補強的 icon 都需列入圖片需求表。生詞頁補圖需先寫明候選頁、剩餘空間判斷與是否補圖的理由；未通過空間與必要性檢查者不列入生圖。Prompt 必須要求一致教材風格、每格獨立；若圖片內需文字、字母、數字或字幕，必須在圖片需求表中明確指定；每個 prompt 最多 16 張圖，超過 16 張需拆批。

圖片生成另須遵守授權閘門：先交付圖片位置與完整 Prompt 給教師確認；確認後再取得是否由助理操作 ChatGPT 生圖的明確同意；正式教材圖片只使用 ChatGPT 生成，不改用其他自動生圖工具。Codex 內建 `image_gen` 只有在教師／使用者明確核可時才可作為例外操作；未核可前，即使圖片需求表與 Prompt 已確認，也不得使用 `image_gen` 生圖。生成後只下載與裁切，等待教師檢查；教師確認裁切素材後才可嵌入 PPT。

## 11. 製作 HTML 投影片（依使用路線）

### editor 路線（教材包生成後）

1. 在 editor 教材資料庫讀取／貼上教材或匯入 `.lesson.json`，建立 `lessonPackage`、逐頁 `sources` 與 `items`；需要批次抽取時才以 `prepare_lesson_package.py` 處理。掃描 PDF 無文字時先取得 OCR，不能臆造。教師核對來源、語意、程度、題型、答案與指令後，按 UI 生成，或以可選的 `build_course.cjs` 生成，再在根目錄 `index.html` 開啟本課 `.slides.json`。
2. 檢查生成內容與 `items` 對應，確認教師備註不出現在學生畫面；不要把舊 HTML、Manifest、歷史 QA 勾選或自動生成結果當成核可。內容修改必須回寫 `items`／來源並使受影響核對失效，位置、尺寸與樣式修改只寫入 `layoutOverrides`。
3. 下載 `.slides.json` 作為可攜備份，重新開啟確認 `lessonPackage`、`sources`、`items`、文字、圖片、位置、`layoutOverrides`、順序與正反面，再於核對通過後匯出獨立 HTML。列印 PDF 時只代表各頁正面；未核對的草稿仍可下載，但不得正式放映或匯出。

### 舊產生器路線

在 `ai-teaching-material-system-main` 中製作。

建議輸出路徑：

```text
ai-teaching-material-system-main/output/kn2/lesson-{{lesson_number}}/
```

若本課使用生成圖片，圖片流程需依 `05_KN2圖片生成與嵌入流程.md` 執行。原始生成圖保留於該課 `素材整理/generated/raw/`，裁切後單張圖保留於該課 `素材整理/generated/cropped/`，HTML 輸出時複製到 `output/kn2/lesson-{{lesson_number}}/slides/assets/generated/`。

圖片流程不可直接跳到嵌入：未經教師確認圖片需求表與 Prompt，不得生圖；未經教師明確同意由助理操作 ChatGPT，不得操作 ChatGPT；正式教材圖片只使用 ChatGPT 生成；未經教師／使用者明確核可，不得使用 Codex 內建 `image_gen`；裁切完成後須先交付教師檢查，未確認前不得放入 PPT。

製作原則：

- 使用 Original Course 風格。
- 不修改核心產生器，除非必要。
- 每頁 HTML 簡潔，適合 960 x 540 課堂投影。
- 若圖片用來取代 SVG、placeholder 或 HTML/CSS 暫時視覺元素，需確認 HTML 已引用新圖片，且該頁不再引用舊素材。
- 生詞頁圖片放在右側例句或 AB 對話下方空白處，並以右側內容區置中；補圖前先確認右側下方可用高度與教學必要性，約 `140px` 以上才可考慮小圖，約 `90px` 到 `120px` 原則上不補；圖片可放大，但不得遮住文字、壓頁尾、造成例句不必要換行、縮小字級、壓縮行距或破壞超綱標注。
- 圖片造句頁需確認圖片和提示詞、答案一致；四格圖大小、風格與視覺權重需一致。
- 每次重新產出 HTML 後，投影片頁面引用的 CSS/JS 需帶版本參數。
- 下方工具列、Present 模式、PDF 匯出、畫筆、螢光筆、橡皮擦、刪除物件與圖形工具需符合 `02_KN2課堂PPT模板.md` 的 HTML Presenter 工具列規則。
- HTML presenter 需用網址 hash（如 `#slide-12`）保留目前頁碼；重新整理後主投影片與左側 `Mục lục` 縮圖側欄都要停留在該頁附近，active 縮圖需在側欄可視範圍內。
- 每頁左下角來源文字只顯示課本頁碼。
- 每頁右下角顯示 `KN2 L{{lesson_number}} · {{current}}/{{total}}`。
- 每頁上方固定頁型 Banner；頁型 icon／字標依模板設定。
- 生詞、語法、練習、功能句、口語任務代表頁需對照 KN4 版型檢查一次。
- HTML presenter 需有左側縮圖側欄；Present 模式可隱藏或縮小側欄，但投影片比例不可變形。

## 13. HTML PPT 檔案編號與目錄同步（僅舊產生器路線）

HTML PPT 必須分開管理目錄順序與課程頁碼：

- `deckIndex` 是目錄中的實際 PPT 順序，從 1 開始連續編號。
- `lessonPage` 僅為舊教師審核稿的頁碼，可因刪頁而跳號；課本頁碼另外存入 `textbookPages`，不可由投影片序號推算。
- `fileName` 必須依 `deckIndex` 產生；目錄第 21 張必須是 `slide-21.html`。
- 投影片頁碼依 `deckIndex` 顯示；課本來源與課文資訊依 `textbookPages` 顯示；`lessonPage` 只用於追溯舊稿。

### 13.1 生成步驟

1. 建立已確認的頁面順序清單，明確排除刪除頁。
2. 依清單順序建立 `deckIndex`。
3. 建立新的暫存輸出資料夾，保留目前可用版本；以下步驟均在暫存資料夾完成。
4. 依 `deckIndex` 連續寫入 `slide-01.html`、`slide-02.html` 等檔案。
5. 將實際輸出檔名寫入 `MANIFEST`。
6. 目錄 iframe、標籤、導覽、hash 與 PDF 檔名只從 `MANIFEST`／`deckIndex` 取得。
7. 驗證新版本的目錄與投影片後才切換輸出入口，保留上一版供還原；不得只修改縮圖標籤。內容局部修正只重建受影響頁，頁面增刪才同步完整目錄。

### 13.2 生成資料

```js
{
  deckIndex: 21,
  slideId: "grammar-example-a", // 建立後固定，不隨排序改變
  lessonPage: 22, // 僅追溯舊審核稿
  textbookPages: "13-14", // 範例值，實作時逐頁核對來源
  fileName: "slide-21.html",
  content: pageHtml
}
```

## 14. HTML 編號同步驗證（僅舊產生器路線）

完成生成後必須檢查：

- HTML 檔案從 `slide-01.html` 連續至最後一頁，沒有跳號或舊檔案。

- 重新整理或使用新版本參數後，不得載入舊版目錄或舊版 CSS／JS。

## 15. 編號錯誤處理（僅舊產生器路線）

若發現目錄順序與檔名不同步，停止交付，重新執行完整生成流程。不得只修改下方標籤，必須同時檢查頁面清單、輸出檔名、`MANIFEST`、iframe、導覽與 PDF 命名。
