# 課程編輯器使用說明

給製作 KN2／KN4 投影片的教師：教材包完成來源整理與教師核對、生成 `.slides.json` 後，用滑鼠作可選的文字／圖片／版面微調，完成後保存可再編輯的課程檔。editor 不取代讀教材、建立教材包或內容核可。

## 第一次使用

解壓縮下載的資料夾，保留 index.html 與 editor 資料夾的位置，雙擊最外層 index.html。建議在電腦上的 Chrome 或 Edge 使用。手機可開啟，但拖曳排版以桌面為主。

正式新課先讀課本與教師核可資料，在 editor 的「教材與課程資料庫」讀取／貼上文字教材或匯入 `.lesson.json`，建立 `lessonPackage`、逐頁 `sources` 與 `items`，完成來源、題型、答案、指令、超綱標注與核對後按「核對完成，生成 PPT」。需要批次處理時，才可用 `scripts/prepare_lesson_package.py` 整理文字檔或有文字層的原生 PDF，再用 `scripts/build_course.cjs` 生成投影片。掃描 PDF 沒有文字時必須先取得 OCR，不能臆造內容；AI 或教師整理的草稿也不等於核可。

「新課程」會建立新的教材包並立即開啟「教材與課程資料庫」，是正式的新課入口：先讀取／匯入教材、保存原頁碼與文字、整理 `items`，逐頁與逐項核對後按「核對完成，生成 PPT」。生成前投影片畫布與格式工具保持鎖定，不能繞過教材資料庫直接自由製作；「開啟課程」可找此瀏覽器最近課程，或讀取已生成／下載的 `.slides.json`。「匯入製作稿」只接受含 `頁碼`、`檔名`、`投影片畫面文字` 欄位的本專案 Markdown 表格，保留所有列，完整原文放在各頁教師備註。這是待溯源文字草稿，不重建舊版面、圖片、分組、正反面、頁型或答案；答案可能與題目同時出現，完成來源與核對前不能正式上課、放映或匯出。舊稿始終可下載備份。

## 調整一頁

- 點選物件後拖曳移動；拖曳右下角控制點改大小。方向鍵微調 1 px，Shift＋方向鍵移動 10 px。
- 雙擊文字直接輸入；或在右側文字欄修改。可調字級、文字色、底色、粗體與對齊。
- 「圖片」加入 PNG、JPG、WebP 或 GIF，單張上限 10 MB；「替換圖片」保留原來的位置與尺寸。圖片以完整比例放入框內。
- 「翻牌」與「答案」都有正面文字及背面／答案欄；按「開始放映」後點卡片檢查兩面。
- 「鎖定位置」避免誤拖；複製物件、置中與前後層次在右側。左側可新增、複製、刪除及上下移動整頁。
- 復原：Ctrl／⌘ Z；重做：Ctrl／⌘ Shift Z。歷史暫存在目前開啟狀態，切換或重新開啟課程後重新累積。
- 出現文字放不下的提醒時，放大文字框或拆成兩頁；提醒只檢查目前正面的文字框，背面仍要在放映中檢查。

## 保存與交付

1. 等到「已儲存於此瀏覽器」，再按「下載課程檔」。這份 `.slides.json` 包含 `lessonPackage`、`sources`、`items`、投影片、`layoutOverrides`、圖片與教師備註，可以傳到另一台電腦繼續編輯。
   內容若在 editor 中修改，必須回寫對應 `items`／來源，該項核對狀態會失效；重新核對後才可生成或正式交付。位置、尺寸與樣式修改則保存在 `layoutOverrides`，重建時應保留。
2. 按「開啟課程 → 選擇課程檔」重開備份，確認修改保留。
3. 確認教材包與受影響 `items` 已核對後，按「匯出簡報」下載單一 HTML，用瀏覽器離線放映。它不包含教師備註；用左右鍵換頁，點卡片揭示答案。未核對的草稿可下載備份，但不能作正式放映或匯出。
4. 需要 PDF 時按「列印 / PDF」，在瀏覽器選另存 PDF，關閉列印頁首頁尾，使用原尺寸。PDF 只印各頁正面，互動、背面答案與教師備註不會一起印出。

正式放映、匯出與列印前的交付檢查會實際量測每頁正面及翻牌／答案背面的文字；只要有文字溢出或超出安全區，就會停止正式放映、HTML 匯出與列印，請放大文字框或依題目順序拆頁。這項程式檢查只處理可量測的版面條件，教師仍須判定內容語意與程度。

若教材資料庫內容與目前投影片不一致，系統會鎖定舊畫布、格式工具與鍵盤移動；請先回教材資料庫完成核對並重新生成，避免舊畫布覆蓋新內容。核對後重新生成才會解除鎖定。

瀏覽器保存不是雲端同步。清除網站資料、使用無痕模式、更換瀏覽器或更動資料夾路徑可能找不到最近課程，請保留下載備份。若出現「尚未保存」，先下載課程檔再關閉視窗。同時開兩個分頁編輯同一課時，較舊分頁會停止自動保存，避免蓋掉另一份修改；請下載舊分頁備份後重新開啟最新版本。

本版不匯入 `.pptx` 或任意 HTML，不提供 PowerPoint 全功能、多人同步、自由筆畫、分段富文字或自動拼音定位。符合欄位的 Markdown 只作待溯源文字草稿；課程 JSON 是教材包生成後的後續編輯來源。程式只檢查可檢查的結構條件，不自動判定語意、程度或全部教學品質；功能通過測試不等於教材內容已核對，首次授課前須用實際投影設備試播。

資料庫內容修改後，舊畫布與格式工具會暫停編輯，避免舊文字覆蓋新內容。核對並重新生成後即可繼續版面微調。

若不希望本頁左右切版，可按「本頁改為上下版面」。它只調整目前頁面的標準標題、說明、正文與生詞／例句位置，不修改內容；可以復原，重新生成會保留。額外自加物件維持原位，長文字仍要檢查是否需要拆頁。
