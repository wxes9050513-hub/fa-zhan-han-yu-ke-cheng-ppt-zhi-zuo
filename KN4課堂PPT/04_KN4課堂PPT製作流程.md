# KN4 課堂 PPT 製作流程

> 執行順序與共用規格以根目錄 `製作契約.md` 為準；本文件保留 KN2／KN4 各自的課程與頁型內容。

本流程用於製作 KN4 HTML 課堂投影片。新課或內容變更固定先讀課本，在 editor 教材資料庫建立／更新教材包與結構化 `items`，完成來源與教師內容核對後按 UI 生成，或以可選的 `scripts/build_course.cjs` 生成 `.slides.json`；生成後才可用本倉庫根目錄 `index.html` 的 editor 作可選手動微調。既有舊課仍可沿用朋友本機的 `ai-teaching-material-system-main` 舊產生器；兩條輸出路線的共同內容規則以根目錄 `製作契約.md` 為準。

`scripts/prepare_lesson_package.py` 可整理文字檔與有文字層的原生 PDF；掃描 PDF 沒有文字時需先取得 OCR，不能臆造內容。教材包寫入 `lessonPackage`、逐頁 `sources` 與 `items`；AI／教師整理不等於教師核可，程式結構檢查也不取代語意與程度判定。符合 `頁碼`、`檔名`、`投影片畫面文字` 欄位的 `HTML_PPT製作稿` 匯入 editor 只作保留全部列的待溯源文字草稿，不會重建舊版面、圖片配置、互動或答案；未完成來源與核對前不得正式放映或匯出。舊產生器路線才需要 HTML_PPT 製作表、Manifest 與舊 presenter 檢查。

## 六項通用排版規則

**共用主要內容區左右內距**：所有頁型均以 `960 x 540` 為投影片畫布，主要內容區距投影片左、右邊界各 `27px`；頁型專屬卡片、來源與頁碼仍須在此安全區內另行排版。

1. **段落間距**：例句與例句、題目段落與題目段落之間使用 `6px`；AB 對話視為同一個例句區塊，不拆成多個獨立排版容器。
2. **同一句內部自動換行**：無超綱標注使用 `line-height: 44px`；含超綱標注且可能換行或實際換行時，外層文字區塊使用 `line-height: 60px`，超綱詞內部行盒固定 `line-height: 42px`。
3. **超綱生詞標注**：使用 inline 格式，拼音在漢字上方、越南語在漢字下方；拼音與越南語字級皆為 `9.33px`，拼音相對漢字的排版偏移參考 `-5px`、越南語相對漢字的排版偏移參考 `-4px`；一般漢字與超綱漢字需同基準線／同視覺高度。
4. **編號例句換行對齊**：`1.`、`2.` 等標號需獨立成標號欄，句子獨立成句子欄；句子換行時第二行對齊句子欄第一個漢字，不對齊標號。
5. **練習頁容量與拆頁**：練習頁若實際渲染後超出 PPT 安全區，永遠優先依題目順序拆成兩頁或多頁；不得先以縮小字體、壓縮行距、縮短題目或刪減答案槽硬塞同一頁。
6. **HTML presenter 狀態保留（舊產生器路線）**：`index.html` 需用 `#slide-XX` 保留目前頁碼；重新整理後主投影片需停留在同一頁，左側 `Mục lục` 縮圖側欄也需自動捲動到目前 active 頁縮圖所在位置，不可跳回第一頁。editor 路線依 `.slides.json` 的固定頁面 ID 與匯出 HTML 的頁面位置保存狀態。

**排版修改後複檢**：每次調整 PPT 排版後，必須重新檢查該頁是否符合通用格式標準，不可只檢查剛修改的局部。通用格式標準至少包含：960 x 540 安全區、主要內容區左右各 `27px` 內距、上方 Banner、左下來源、右下頁碼、段落間距、同一句內部自動換行、超綱生詞格式與漢字對齊、題目／例句換行對齊、該頁型專屬版面規則；練習頁若超出，仍優先拆頁。

## 1. 建立課程資料夾

1. 在 `KN4課堂PPT` 中找到對應課次子資料夾。
2. 每課子資料夾建議放：
   - `{{lesson}}課堂PPT架構.md`
   - `{{lesson}}課堂PPT教師審核稿.md`

## 3. 整理課堂架構

依 `01_KN4課堂PPT架構.md` 建立該課完整頁面表。

必須包含：

- 封面，2 分鐘。
- 一個暖身活動。
- 封面不顯示 `45 phút x 3 buổi`；不可重複放置課程名稱與 Lesson 資訊，若已放 `KN4 - Bài {{lesson_number}}`，不可再放 `Kỹ năng Nói 4 - Bài {{lesson_number}}`。
- 封面左文右圖時必須固定文字欄與圖片欄並保留安全距離；標題以 PPT 上下邊界垂直置中，並在 PPT 左邊界到右圖左框的可用區域內水平置中。長課名需縮小並可在逗號後換行，避免與圖片重疊。
- 暖身快速回答題目用中文簡體；上方小 Banner 標題使用越南語 `Khởi động`，不可使用中文「暖身活動」；問題區不使用白底框；問句字級需依長度縮小，儘量一行呈現但不得超出版面；提示句型與提示生詞放在問句下方橫式排列；`Mẫu câu` 與 `Từ gợi ý` 標籤字體、字級、字重與大小寫樣式需一致。
- 暖身若採「看圖說故事」，內容標題使用越南語並置於左上側；故事圖需為 3~4 張，從左到右分散排列在 PPT 中央、標題下方。
- 暖身提示句型若需要留空，不使用中文省略號 `……`，改用 baseline 位置的 `......`。
- 暖身提示生詞需顯示上方拼音、中央漢字、下方 `（越南語）`；預習回收頁的所有提示生詞也依同一格式呈現，不得只顯示漢字。
- 所有頁型只要出現中文例句，都需套用漢字對齊規則；一般漢字與超綱標注漢字需保持同一基準線／同一視覺高度，拼音與越南語標注不得撐高或壓低該行漢字。例句若位於 `Mẫu câu`、`VD1`、`VD2`、`Hội thoại` 等標籤下方，標籤底部到例句漢字以 `6px` 為基準，不論該句是否含超綱標注。
- 第一層：段落間距。所有頁型中，例句與例句之間、題目段落與題目段落之間統一用 `6px`；適用於生詞例句、語法／句型例句、功能句例句、練習題段落與 MỞ RỘNG 例句。AB 對話視為同一個例句區塊，不拆成多個獨立排版容器；A/B 換行不靠段落間距控制，改由第二層 `line-height` 控制。
- 第二層：同一句內部自動換行。單一句子、單一題目或同一組 AB 對話若在同一區塊內自動換行，用 `line-height` 控制行距。無超綱標注時以 `line-height: 44px` 為基準；含超綱標注且可能換行或實際換行時，外層文字區塊用 `line-height: 60px`，超綱詞內部行盒固定 `line-height: 42px`，並保留拼音相對漢字的排版偏移參考 `-5px`、越南語相對漢字的排版偏移參考 `-4px`，避免上行越南語與下行拼音重疊。
- 練習頁若實際渲染後超出投影片安全區、頁尾來源或頁碼區，第一方案永遠是依題目順序拆成兩頁或多頁；不可優先用縮小字體、壓縮行距、縮短題目或刪減答案槽硬塞同一頁。字級微調只能作為拆頁後的細部排版。拆頁後需同步更新檔名、頁碼、總頁數、Manifest、縮圖與對應製作稿／審核稿。
- 編號例句、編號題目或功能句例組若使用 `1.`、`2.`、`3.` 等標號，需拆成「標號欄＋句子欄」；標號欄固定於左側，句子欄從第一個漢字開始。句子自動換行時，第二行對齊句子欄第一個漢字，不對齊標號；若句中有超綱標注，仍同時套用漢字對齊、超綱標注與第二層 `line-height` 規則。
- 課文處理採「段落循環」：依每課實際課文／對話段數，逐段完成「預習回收 → 該段核心生詞講解 → 該段語法／句型講解 → 對應語法練習」。不預設一定三段課文；每一段課文都完成一輪後，才接功能句學習、團體任務與收尾。
- 每段課文／對話的「想一想、说一说」，一題一頁。
- 生詞直接講解，不做總覽頁。
- 語法講解與一般語法課本練習。
- 功能句學習與功能句練習，學一個做一個。
- 團體任務：課堂準備、課堂 Formative 錄音、抽 5 組上台。
- 課本「词语扩展任务」若加入，只放在團體任務主活動後作 `MỞ RỘNG`；一頁一個課本指定目標詞，課本已給完整答案的示例詞不放入學生頁，也不作角色扮演答案詞庫。
- 收尾與作業提醒，1 分鐘；最後一頁使用 `Closing` 下课页，同時放本課回家作業 QR Code 與下一課課前預習 QR Code。

## 4. 選生詞

AI 先判斷哪些生詞需要課堂特別講解。

選詞原則：

- 影響課文理解。
- 影響口說輸出。
- 學生容易誤用。
- 可用於生活情境。
- 可延伸功能或文化用法。

頁面原則：

- 1-2 頁一個生詞。
- 若一頁有 2-3 個生詞，改用頁型 D-2：將左側生詞區拆成單欄垂直排列的 2 或 3 張等寬、等高獨立閃卡；2 個生詞上下兩張，3 個生詞上中下三張，不得拆成左右分欄。每張卡各自提供正面拼音＋漢字、背面越南語詞性＋越南語翻譯，並各自具備獨立翻牌動畫。只有 1 個生詞時沿用一般單卡。
- 生詞、拼音或越南語過長時，單卡先優先縮小漢字；縮小後仍無法容納，才在自己的文字區塊內換行。此規則同時適用單卡、雙卡、三卡正反面；不得超出卡片、造成重疊、改變其他卡片尺寸或破壞右側例句版面。
- 每頁包含漢字、拼音、越南語詞性、越文；HTML 畫面中左側白色生詞框做成閃卡，正面只放拼音＋漢字，背面只放兩行：越南語詞性在上、越南語翻譯在下；不顯示 `Loại từ`、`Nghĩa` 等欄位標籤。
- KN4 生詞頁詞性必須使用越南語，例如 `động từ`、`danh từ`、`tính từ`；詞性用青綠色 `#5AACAC`，越南語翻譯用深藍色 `#1A3A5A`，兩行水平、垂直置中，間距約 `6px`。離合動詞與成語的類型標注仍放在正面漢字下方，不放在背面。
- 製作與 QA 時，必須確認背面只有上述兩行資訊，未出現 `Loại từ`、`Nghĩa` 等標籤，且兩行的顏色、置中與間距符合規格；離合動詞／成語標注仍只檢查正面漢字下方。
- 生詞頁右側互動問句或例句統一標為 `Mẫu câu`，不得用 `Câu hỏi`；例句採固定排版基準：右側卡片左內距 `10px`、右內距 `10px`、卡片寬度 `546px`、文字可用寬度 `526px`、卡片右側邊界到投影片邊界 `27px`、右側卡片左側邊界到左側卡片右側邊界 `10px`；例句主字級 `22pt`、一般同句換行 `line-height: 44px`、段落間距依第一層通用規則用 `6px`；含超綱標注且可能換行或實際換行時，依第二層規則使用外層 `line-height: 60px`、超綱詞內部 `line-height: 42px`；超綱標注的拼音與越南語字級 `9.33px`；拼音相對漢字的排版偏移參考 `-5px`，越南語相對漢字的排版偏移參考 `-4px`；以 `22pt` + Noto Sans SC 渲染後，漢字高度以未縮放畫布的實際字形為準，`42px` 僅為超綱詞內部行盒高度。以上需用截圖或 DOM 屬性。
- 生詞頁右側例句、互動問句或 AB 對話中，若出現本頁生詞，需用黃底紅字突出；合併多詞頁需分別突出所有本頁生詞；合成詞拆開出現時，也需突出可辨識的生詞部分。
- AB 例句整體只放在一個獨立內容區塊內，不拆成多個 `content-card` 或多個獨立排版容器；A/B 可分行或自然換行，但同一段對話需共用同一組字級、段落間距與第二層 `line-height` 規則。
- 圖片不是必須，但可用圖片、icon 或簡潔視覺元素優化版面；封面、下课页、情境練習頁優先考慮。
- 生詞頁補圖不是預設必做；HTML_PPT 製作稿定稿後、圖片生成前，先檢查每個候選生詞頁的右側例句或 AB 對話下方空間。可用高度約 `140px` 以上才可考慮約 `180px x 110px` 小圖；約 `90px` 到 `120px` 原則上不補，除非教師指定。優先補具體名詞、具體物品、明確動作或生活／校園場景詞；抽象詞、語法性強的詞、功能詞或例句已足夠清楚者不優先補。不得為補圖縮小例句、壓縮行距、破壞超綱標注或造成例句不必要換行。
- 若使用 ChatGPT 生成單字小圖，需根據生詞例句判斷是否適合放圖；可用 contact sheet 批次生成並按頁裁切；圖片內文字、字母、數字或字幕依教師指定與圖片需求表。
- 例句儘量使用問句。
- 可用 AB 對話替代例句。

補充辨析頁原則：

- 若上方 Banner 已顯示頁型，白框內不可再放 `Phân biệt / Bổ sung` 等重複小標。
- 不使用 `cách dùng` 作為畫面標籤；直接呈現對比詞與說明。
- 對比詞放在各自解釋文字上方置中，使用不同標色。
- 越南語說明短句句首第一個字母必須大寫，例如 `Dùng khi...`。
- 左右例子區都需顯示 `VÍ DỤ`。

## 5. 整理「想一想、说一说」

每題一頁。

每頁必放：

- 課本問題。
- 課文資訊：`课文：P{{page_range}}《{{text_title}}》`，放在問句上方；課文標題必須加書名號《》。
- 提示生詞。
- 提示句型。
- 參考答案，放在閃卡背面；必須是完整中文句子，不使用片語式答案或教師備註式答案方向。
- 教師備註。

不要放完整課文，不要求學生背誦課文。

版面規則：

- 上方小 Banner 顯示 `Ôn phần chuẩn bị`。
- 問句卡內不可再重複放 `Ôn phần chuẩn bị`。
- 課文資訊與問題卡需依 PPT 上下左右安全邊界整體置中。
- 問題儘量一行呈現，不得超出版面。
- 問題卡改為閃卡：正面為問題，背面只放參考答案句子，不顯示 `答案` 標籤；點擊工具列下一步或卡片本身需有翻牌效果。
- 閃卡背面答案必須是學生可直接朗讀或仿說的完整中文句子，水平左對齊、垂直置中在白色閃卡框中；無超綱標注時換行使用 `line-height: 44px`；含超綱標注且可能換行時，外層使用 `line-height: 60px`、超綱詞內部使用 `line-height: 42px`；若答案包含多個理由或步驟，採一個理由／步驟一行；先利用上半部安排課文資訊與閃卡，優先維持可讀字級，再將提示區配置於下方，並確認不重疊；例如 `办银行卡需要带护照、学生证或者其他有效证件。`
- 預習回收頁若有 `Từ gợi ý` 或 `Mẫu câu`，課文資訊、問題閃卡、`Mẫu câu`、`Từ gợi ý` 需依序放入同一個主內容區；主內容區可定位，但內部區塊採垂直正常流程，不個別固定定位。P05 型間距依序為課文資訊至閃卡 `12px`、閃卡至提示區 `4px`、提示區內兩區塊 `7px`；只有高密度頁可使用專用定位，且必須實際檢查提示區與閃卡、頁碼及來源文字沒有重疊。
- 題目、提示句型、提示詞與背面答案都要做超綱生詞交叉檢查；若保留超綱詞，HTML 呈現為漢字上方拼音、漢字下方 `（越南語）` 翻譯。
- 超綱標注以實際詞素為單位；例如 `利和弊` 只標注 `利`、`弊`，不連帶標注 `和`。
- 預習回收提示較多時，先利用 Banner 下方的上方安全空間排版，避免內容垂直置中造成不必要的上方空白。
- 製作時先建立預習回收主內容區，再依序放置課文資訊、問題閃卡、`Mẫu câu`、`Từ gợi ý`；提示內容變多時讓正常流程推動下方區塊，不能用個別絕對定位硬塞進閃卡區。完成後以 DOM 或截圖確認四區塊的順序、`12px`／`4px`／`7px` 間距，以及與來源文字、頁碼的安全距離。

## 6. 整理語法與句型

每個語法至少包含：

- 使用情境，越南語說明。
- 例句來源核對：先定位課本對應的語法區塊、課文／對話原文與「读一读、试一试」，再整理例句；不得只憑記憶或直接自行造句。
- VD1 優先擷取課文或對話中的原句；VD2 擷取同一語法在「读一读、试一试」中的第一個完整例句，通常是第（1）句。完整例句不得含挖空，且需保留課本文字、標點與語序。
- 若「读一读、试一试」整個對應區塊中沒有完整例句，才允許自行造句；自編例句需符合語法、使用本課可用詞彙，並在教師審核稿中註明「自編例句」，經教師確認後才能進入 HTML_PPT 製作稿。
- 將 VD1／VD2 類型、來源頁碼、區塊／題號、原句與是否自編記錄於教師審核稿；語法標記只作視覺標示，不得改變課本原句。
- 補充例句或 AB 對話。
- 同一句例句中的標點不可被當成新例句分隔；需保留在同一內容區塊。
- 一般語法／功能句課本練習題。
- HTML 語法講解頁白色句型框內只放句型文字，不放 `Mẫu câu` 小標。
- 一般語法講解頁下方依序直向排列 `Cách dùng:`、`VD1:`、`VD2:`、`VD3:` 或 `Hội thoại:`；標籤獨立一行，內容放在下一行，不做成左標題右內容兩欄；標籤與內容可適度放大方便閱讀，必要時自動微縮，但以不超過 PPT 右側安全邊界為準。
- 若同一語法有兩個並列結構、兩種用法，或 `A vs B` 比較型語法，使用「文法特殊頁 - 雙區塊」取代原本的 `vs` 特殊左右比較頁：上方主句型大卡置中，下方兩個等寬白底區塊；每格最上方放結構／比較項並使用不同標色，標題置中，說明、`VD` 與例句依序排列，例句置左，兩格內部高度一致。
- 若同一語法有三個並列結構，可使用「文法特殊頁 - 三區塊」：上方主句型大卡、其下 `Cách dùng`、下方三個等寬白底區塊；每格最上方放結構並使用不同標色，結構置中，`VD` 與例句置左，三格內部高度一致。
- 雙區塊或三區塊頁若使用編號例句，各區塊需同步使用「標號欄＋句子欄」；句子換行時對齊句子欄第一個漢字，不對齊 `1.`／`2.` 等標號。
- 例句或對話中的本課語法內容需用黃底紅字突出。
- 語法頁所有中文例句都必須套用漢字對齊規則；若例句含超綱 inline 標注，一般漢字與超綱漢字需保持同一基準線／同一視覺高度，拼音與越文標注不得撐高或壓低該行漢字。

練習題規則：

- 建立練習題目池前先做內容分類：詞語練習一、二、三不自動製作成 PPT 練習頁；只有教師明確指定時，才可列入課堂 PPT 結構。詞語可繼續用於生詞講解、預習回收或其他已指定的課堂活動。一般語法與功能句練習依下列既有規則處理。
- 一般語法練習採「作業先保留、PPT 後安排」。先建立完整的一般語法題目池，依回家作業需求標記保留題，再將未保留的一般語法課本題安排至 PPT。
- 一般語法每組拆頁前預設 3-5 個完整題目、情境或對話區塊；多個空格、同一組 AB 對話或同一情境中的多句內容只算 1 題。若保留作業題後不足 3 題，才補同一題型、同一語法的自編題；自編題須標記 `自編補足`、唯一 ID、題幹與答案，並經教師審核。
- 功能句練習另行處理：課堂頁必須完整呈現課本「功能項目練習」的情境、題幹、對話、挖空位置與題數，不套用一般語法的 3-5 題或作業保留規則；內容過多時依課本順序拆頁。
- 功能句回家作業以同一功能為來源另建改寫題，使用獨立作業題目 ID；不得直接挪用課堂功能題，並須排除高度相似變體。
- 製作練習頁時為每題建立唯一題目 ID，並將課堂使用、回家作業保留／改寫或不選作業狀態寫入教師審核稿。
- 不得以 HTML 頁碼或投影片編號取代課本頁碼／題號；題目 ID 必須能回溯到課本原題或明確標記自編／作業改寫來源。
- 回家作業製作時必須讀取最新 PPT 題目登記表，排除課堂已使用題目、自編補足題及高度相似改寫題；一般語法優先使用保留題，功能句使用獨立改寫題。
- 語法練習採「一個語法一組練習（可依容量拆成連續頁）」，並緊接在對應語法講解頁後；不同語法不可合併成同一頁綜合練習，除非教師明確要求。
- 若課本題情境不明，改成 AB 對話填空。
- 自製或教師要求改寫的語法練習題需避開前一頁語法例句與課本課文原句的重複或高度相似題；不可只替換少量詞語、人物、時間或數字。若教師指定使用課本原題，則以完整保留課本題為優先。
- 若 AB 對話經教師判斷會造成語境重複或不自然，可改為不超過三句的情境題；同一頁若改為情境題，所有題目須統一題型，並以課本原句為主，只補充必要情境、保留原句挖空位置，不任意改寫原句。
- 保留原語法目標。
- 語法講解如果只有單句例句，放兩個單句；如果為 AB 對話，放一個對話即可。
- 製作練習頁前先判斷頁型：G4 情境造句、G5 完成句子、G6 完成對話、G7 判斷填空；問答翻牌用 G1，圖片造句用 G2，圖片閃卡用 G3。同一頁以一種題型為主。
- 練習頁上方 Banner 已有 `Luyện tập` 時，頁面內不可再重複放 `Luyện tập`；頁內文字說明只放 1-2 句越南語操作指令，文字使用綠色 `#5AACAC`；不放 `Cách làm`、語法名稱、句型名稱或額外語法說明。
- G4 情境造句：給越南語情境，讓學生用目標語法造完整中文句；情境要清楚引導語法，答案槽可另起一行，底線需固定長度且可略偏長；中文答案用點擊紅字帶入。
- G5 完成句子：給中文句子或提示詞庫，讓學生補入目標語法、句型或詞語；提示詞庫只放需選用或替換的詞。
- G6 完成對話：用目標語法完成 AB 對話；`A:` 與 `B:` 必須分行；同一組 AB 對話不拆成多個獨立排版容器；答案需是完整中文句子。
- G7 判斷填空：用於判斷該填哪個結構、詞語或是否不需填入；若無需填入，用 `X`；題目需讓學生能判斷語境差異。
- 若練習改為「問答」型，使用「練習頁 - 問答」：頁面只放 1-2 句綠色越南語操作指令，不放 `Cách làm`、語法名稱標籤或額外語法說明；題目由上至下排列，一行一題；每題做成獨立翻牌卡，正面題號＋問句，背面完整句答案，點同一卡可翻回；目標語法／句型在答案中用黃底紅字突出。
- 若練習改為「圖片閃卡」型，使用「練習頁 - 圖片閃卡」：頁面只放 1-2 句綠色越南語操作指令；建議 4 題；正面為圖片＋題號，背面為完整中文答案；預設四卡橫向排列，若圖片細節多或答案較長可改 2x2；圖片需清楚對應答案情境，圖片內文字、字母、數字或字幕依教師指定與圖片需求表；目標語法／句型在答案中用黃底紅字突出；單頁 HTML 與 `index.html` presenter 都需可直接點擊卡片翻面／翻回。
- 填空練習題目由上至下排列，答案不可做成整張答案卡；需用點擊動畫將紅色答案帶入空格；不顯示 `Bấm để hiện...` 等點擊提示文字。
- AB 對話填空中 `A:` 與 `B:` 必須分行，不可接在同一行。
- 課本題號如 `（1）`、`（2）`、`（3）` 需統一做成綠底綠字題號標籤；若同一組練習因版面拆成多頁，後頁題號需承接前頁，不可重新從 1 開始；若 `Tình huống（n）：` 已作為情境題號，作答句前不可再重複放 `(1)` 等題號；情境題的題目／作答句統一左對齊，不因重複題號預留左側縮排；若句子換行，第二行首字需對齊第一行句子首字，不對齊題號；同一題的延續對話句也需對齊該題正文首字；`Tình huống（n）：` 情境說明若換行，第二行需對齊描述正文首字，不對齊情境標籤。
- 非疑問句以 `吧` 結尾時，句末使用 `！`；疑問句或反問句保留 `？`。
- 圖片造句練習頁左側放圖片，右側依序放越南語指令、`Từ gợi ý`、`Mẫu câu`、點擊答案；指令可用 `Đặt câu theo tấm hình`，提示生詞與提示句型放在指令下方，不使用大段說明文字。

## 7. 整理功能句

功能句固定採三頁結構：先做功能句說明頁，再做該功能對應句型的實用例句頁，最後做功能句練習頁。功能句說明頁一頁只放一個功能項目；左側白卡放 `Chức năng` 與功能名稱，KN4 功能名稱使用中文；兩者垂直置中，`gap`／`margin-top` 以 `6px` 為基準；功能名稱字級以 `30px` 為基準，需單行呈現，若字體過大需自動縮小到不換行且不超出白框。右側白卡標籤統一用 `MẪU CÂU`，標籤下方只放該功能對應的課本功能句或教師指定功能句；閃卡正面或投影片可見正面不放 `Dùng khi...` 使用情境說明。不同功能不可同頁混放，若同課有多個功能，需拆成不同功能句說明頁。只有教師指定的例句頁才採單欄直排，`Chức năng` 在上、例句在下，例句由上至下排列，不使用左右雙欄，並將功能句型套用黃底紅字生詞／語法標記；未指定頁面沿用原有版型。製作教師審核稿時，必須先確認並標出功能句說明頁或對應例句頁可套用的句型／語塊重點；未確認前不得進入 HTML_PPT 製作稿或 HTML PPT 製作。功能句練習必須完整保留課本情境、題幹、對話內容、挖空位置與題數，不得因回家作業保留而挪走課本題；若內容超出，優先拆成一題一頁或兩題一頁，不以縮小字體硬塞。自製或教師要求重寫的功能句練習，需根據前一功能句說明頁或例句頁已標出的句型／語塊設計新情境，不可只把前頁例句挖空後填回答案。功能句練習頁上方只放 1-2 句綠色越南語操作指令，例如 `Hoàn thành hội thoại.`，不使用 `Cách làm` 或功能／語法名稱標籤；題目前需加入課本中的該題情境說明。功能句課堂題數依課本實際題數，不套用一般語法 3-5 題標準；若只有一個情境／一段對話，只能算一題；題號只放在第一句作答句前，不可逐句自動編號；多句同題對話需對齊題號後正文首字。

P58 型功能句情境對話練習另依下列規格製作：每題先放 `Tình huống（n）：` 情境說明，再放作答句／對話填空；`Tình huống（n）` 已作為題號時，作答句前不再重複 `(1)` 等題號；情境與作答句由上至下、左對齊，AB 對話的 `A:`、`B:` 分行，同一題多句對話共用同一個內容區塊；空格答案以點擊動畫紅字帶入，不顯示額外提示文字。題目、對話與答案中的超綱詞依上下拼音／越南語格式標注，段落間距使用 `6px`，同一句內換行使用對應的 `line-height`。若內容超出安全區，依情境順序拆頁並同步更新頁碼、總頁數、Manifest、縮圖及相關製作文件。

若任何頁面完成實際渲染後超出投影片安全區、頁尾來源或頁碼區，必須拆頁保留完整內容，不得以過度縮小或刪減內容處理。功能句練習拆頁時尤其不得刪除課本題。拆頁時維持原題目／例句順序，並同步更新後續 HTML 檔名、Manifest／縮圖清單、總頁數、頁碼、教師審核稿與 HTML_PPT 製作稿；拆頁後需重新檢查新頁與所有順延頁。

每個功能句包含：

- 功能名稱。
- 常用句型。
- 使用情境。
- 課本功能項目練習。
- 標明課本頁數。

介紹功能句需加入文化學習：

- 用問題開頭：給兩個人，問學生誰先介紹給誰。
- 再給答案。
- 補充介紹順序規則。
- 若文化補充拆成獨立頁，頁型用 `Culture`，標題為 `Văn hoá / lịch sử`；上方問題 `Nên giới thiệu ai trước?` 水平置中，問題下方左右兩區塊各放一個人／群體文字＋對應圖像。

## 8. 整理團體任務

班級設定：

- 40 人。
- 兩人一組，共 20 組。
- 每課抽或指定 5 組上台。
- 全班都在課堂完成 Formative 錄音。
- 上台組也要錄音。
- 未上台組不回家錄音。

投影片包含：

1. 團體任務說明＋要求可併入任務執行頁；若任務執行頁已完整說明，刪除獨立任務說明頁。
2. 團體任務執行說明可合併準備、Formative 課堂錄音、5 組上台演練與共通回饋，用完整越南語呈現，並預留 QR Code 空白區；QR 任務執行頁上方顯示 `Nhiệm vụ nhóm`，不再放 `Formative` 膠囊，內容區需重新排版。若製作角色扮演／課堂展示的任務說明頁，使用「團體任務 - 說明頁」：主標題如 `Đóng vai` 使用綠色 `#5AACAC`，後方同一行註明課本實際位置與題名，格式如 `P21, 6-2 课堂展示`；註記用灰色、小一級並與標題基線對齊；主內容區可上調，避免標題上方空白過多，基準 top 約 `68px`；左側白卡放越南語任務條列，右側白卡預留 QR Code；左下角保留課本來源。
3. 若課本有 `词语扩展任务` 且教師想保留，可放在主任務後、收尾作業前，Banner 標示 `MỞ RỘNG`，時間不足可跳過；先確認課本哪些詞是示例、哪些詞是學生要練的目標詞，課本已給完整答案的示例詞不放入學生頁。
4. `MỞ RỘNG` 一頁一個練習詞；頁面上方先放 1 句越南語操作指令，字色用綠色 `#5AACAC`，下方放練習詞，字色用深藍黑 `#1A3A5A`；練習詞不用紅色，不放拼音與翻譯，除非教師另行指定。補充字／詞由上到下單欄排列，一列一題，右側點擊帶入例句答案；若超出版面，優先拆頁。
5. 收尾與作業，1 分鐘；最後一頁使用 `Closing` 下课页，左卡放本課回家作業 QR Code 圖，右卡放下一課課前預習 QR Code 圖。畫面中央標題為 `下课`，上方 Banner 使用勾勾 icon + `下课`。

## 9. 完成教師審核稿

使用 `03_KN4課堂PPT教師審核稿模板.md`。

審核重點：

- 課堂時間是否能跑完。
- 每頁是否有明確口說任務。
- 說明是否為越南語。
- 中文是否為簡體中文。
- 生詞例句是否盡量使用問句。
- 生詞閃卡若有 2-3 個生詞，是否已拆成獨立閃卡、每張卡可獨立翻牌，且正面／背面內容與卡片尺寸符合頁型 D-2。
- 生詞閃卡長文字是否先縮小漢字，再於自身文字區塊換行；正反面是否無超出或重疊。
- 語法練習是否避開回家作業。
- 語法練習是否已標定正確頁型：G4 情境造句、G5 完成句子、G6 完成對話、G7 判斷填空；若為問答翻牌、圖片造句或圖片閃卡，是否分別套用 G1/G2/G3；同頁未混用兩種以上題型。
- 自製或教師要求改寫的語法練習是否避開前一頁語法例句與課本課文原句的重複或高度相似題。
- 語法練習是否一個語法一組（可拆連續頁），並緊接在對應語法講解頁後。
- 內容範圍是否已確認：詞語練習一、二、三未自動列入 PPT；若列入，教師明確指定依據是否已記錄。
- 若使用「練習頁 - 圖片閃卡」，是否符合正面圖片＋題號、背面完整中文答案、單頁與 `index.html` 都可直接點擊翻面／翻回、圖片內文字符合圖片需求表的規則。
- 功能句是否採介紹頁＋練習頁兩頁結構，練習頁是否以 1-2 句綠色越南語操作指令（如 `Hoàn thành hội thoại.`）並加入課本情境。
- 團體任務是否課堂內完成錄音。
- 最後是否已用 `單字、語法資料庫` 做超綱生詞交叉檢查。

教師審核稿最後必做超綱生詞交叉檢查：

- 比對範圍包含學生會看到、說出、填出或錄出的所有中文內容。
- 必查項目包含預習回收題目、預習回收提示句型、預習回收提示詞、預習回收背面答案、生詞例句、AB 對話、語法練習、功能句練習、團體任務要求與參考答案。
- 若超綱詞來自課本題目原文、課本例句或課本指定句，註明「課本原文保留」。
- 自編題目、改寫題、參考答案與學生必須產出的內容若出現超綱詞，先改用已學詞；不能替換時，才依超綱詞規則做上下標記並確認不放入答案。
- 超綱詞保留格式：漢字上方加拼音，漢字下方加 `（越南語）` 翻譯；HTML 製作時不得只用旁註或列表注記；超綱詞不套用生詞黃底紅字，除非該詞本身就是本頁教學生詞。
- 內容審核先確認超綱詞與釋義；HTML 初稿產出後，再用截圖或 DOM 字框量測檢查可見字形距離與漢字高度對齊；若同一句內部換行後出現上行越南語與下行拼音重疊，優先套用第二層 `line-height` 規則：外層文字區塊 `line-height: 60px`，超綱詞內部行盒 `line-height: 42px`。
- 檢查結果必須寫入教師審核稿的「超綱生詞交叉檢查」或「教師最終判斷」。

## 10. 製作 HTML_PPT 製作稿（僅舊產生器路線）

舊產生器路線在教師審核稿通過後，建立 `{{lesson}}HTML_PPT製作稿.md`，再製作 HTML。新課或內容變更的 editor 路線不以本稿作為正式來源，而是先建立並核對教材包的 `lessonPackage`、逐頁 `sources` 與 `items`，再按 UI 生成 `.slides.json`，或使用可選的 `build_course.cjs` 批次生成。若要匯入舊稿，檔案必須含 `頁碼`、`檔名`、`投影片畫面文字` 欄，匯入後只建立保留全部列的待溯源文字草稿，不能繞過來源、答案、指令或核對。

製作稿用途：

- 固定已通過的頁碼、堂次、時間與活動順序。
- 將每頁轉成 HTML 製作欄位：檔名、頁型、畫面主標、投影片畫面文字、互動／動畫／素材、教師備註。
- 確認投影片畫面上的說明文字是越南語，中文內容是簡體中文。
- 標明需要或建議使用的圖片、icon、點擊答案、動畫或 Formative 規則的頁面。
- 最後一頁需標為 `Closing` 頁型，並寫明左卡回家作業、右卡下一課課前預習的 Formative 連結；製作 HTML PPT 時需先確認兩個連結對應正確，再轉成 QR Code 圖並嵌入卡片。
- 教師備註只放製作稿或 presenter notes，不放進學生畫面。
- 若本課要使用 ChatGPT 生成圖片，需依 `05_KN4圖片生成與嵌入流程.md` 在 HTML_PPT 製作稿中新增圖片需求表與 prompt。封面圖可單獨生成；單字、補充辨析、文化快問可整理成 contact sheet 批次。HTML/CSS 畫出的視覺元素、暫用 SVG、placeholder 圖與生詞頁可補強的 icon 都需列入圖片需求表。Prompt 必須要求一致教材風格、每格獨立；若圖片內需文字、字母、數字或字幕，必須在圖片需求表中明確指定；每個 prompt 最多 16 張圖，超過 16 張需拆批。

圖片生成另須遵守四階段審核閘門：先交付圖片位置與完整 Prompt 給教師確認；確認後再取得是否由助理操作 ChatGPT 生圖的明確同意；正式教材圖片只使用 ChatGPT 生成，不改用其他自動生圖工具。Codex 內建 `image_gen` 只有在教師／使用者明確核可時才可作為例外操作；未核可前，即使圖片需求表與 Prompt 已確認，也不得使用 `image_gen` 生圖。生成後只下載與裁切，等待教師檢查；教師確認裁切素材後才可嵌入 PPT。未完成前一階段，不得進入下一階段。

檔名規則：

- 每頁 HTML 使用 `slide-XX.html`。
- XX 為兩位數頁碼，例如 `slide-01.html`。

## 11. 製作 HTML 投影片（依使用路線）

### editor 路線（教材包生成後）

1. 在 editor 教材資料庫讀取／貼上教材或匯入 `.lesson.json`，建立 `lessonPackage`、逐頁 `sources` 與 `items`；需要批次抽取時才以 `prepare_lesson_package.py` 處理。掃描 PDF 無文字時先取得 OCR，不能臆造。教師核對來源、語意、程度、題型、答案與指令後，按 UI 生成，或以可選的 `build_course.cjs` 生成，再在根目錄 `index.html` 開啟本課 `.slides.json`。
2. 檢查生成內容與 `items` 對應，確認教師備註不出現在學生畫面；不要把舊 HTML、Manifest、歷史 QA 勾選或自動生成結果當成核可。內容修改必須回寫 `items`／來源並使受影響核對失效，位置、尺寸與樣式修改只寫入 `layoutOverrides`。
3. 下載 `.slides.json` 作為可攜備份，重新開啟確認 `lessonPackage`、`sources`、`items`、文字、圖片、`layoutOverrides`、順序與正反面，再於核對通過後匯出獨立 HTML。列印 PDF 時只代表各頁正面；未核對的草稿仍可下載，但不得正式放映或匯出。

### 舊產生器路線

在 `ai-teaching-material-system-main` 中製作。

注意：`ai-teaching-material-system-main` 只作為 HTML PPT 格式、視覺風格與工具欄參考。課程架構、學生程度、頁面內容與活動設計以 KN4 課本、KN4 課前預習、KN4 回家作業、KN4 課堂 PPT 教師審核稿與 HTML_PPT 製作稿為準。

建議輸出路徑：

`ai-teaching-material-system-main/output/kn4/lesson-{{lesson_number}}/`

若本課使用生成圖片，圖片流程需依 `05_KN4圖片生成與嵌入流程.md` 執行。原始生成圖保留於該課 `素材整理/generated/raw/`，裁切後單張圖保留於該課 `素材整理/generated/cropped/`，HTML 輸出時複製到 `output/kn4/lesson-{{lesson_number}}/slides/assets/generated/`。

圖片流程不可直接跳到嵌入：未經教師確認圖片需求表與 Prompt，不得生圖；未經教師明確同意由助理操作 ChatGPT，不得操作 ChatGPT；正式教材圖片只使用 ChatGPT 生成；未經教師／使用者明確核可，不得使用 Codex 內建 `image_gen`；裁切完成後須先交付教師檢查，未確認前不得放入 PPT。

製作原則：

- 使用 Original Course 風格。
- 不修改核心產生器，除非必要。
- 每頁 HTML 簡潔，適合 960 x 540 課堂投影。
- 若圖片用來取代 SVG、placeholder 或 HTML/CSS 暫時視覺元素，需確認 HTML 已引用新圖片，且該頁不再引用舊素材。
- 生詞頁圖片放在右側例句或 AB 對話下方空白處，並以右側內容區置中；補圖前先確認右側下方可用高度與教學必要性，約 `140px` 以上才可考慮小圖，約 `90px` 到 `120px` 原則上不補；圖片可放大，但不得遮住文字、壓頁尾、造成例句不必要換行、縮小字級、壓縮行距或破壞超綱標注。
- 封面與暖身頁需優先檢查文字重疊：封面左文右圖需固定分區，標題需在 PPT 左邊界到右圖左框的可用區域內水平置中，並以 PPT 上下邊界垂直置中；長課名縮小或從逗號處斷行；暖身上方小 Banner 使用越南語 `Khởi động`，問題區不使用白底框，問句儘量單行且不得超出版面，支架放在問句下方且橫式排列，`Mẫu câu` 與 `Từ gợi ý` 標籤樣式一致。
- 預習回收頁需檢查：上方小 Banner 顯示 `Ôn phần chuẩn bị`；問句卡內不重複標題；問句上方有 `课文：P{{page_range}}《{{text_title}}》`；課文資訊與問題卡整體置中；問題儘量一行呈現；問題卡可翻牌，背面只放左對齊、垂直置中的完整句參考答案，不顯示 `答案` 標籤；無超綱標注時答案換行使用 `line-height: 44px`，含超綱標注且可能換行時外層 `60px`、超綱詞內部 `42px`；多個理由／步驟一行一項，優先利用上半部安排閃卡並保留可讀字級，且不與下方提示區重疊；題目、提示與答案中的超綱詞已用上方拼音、下方越南語標注。
- 語法講解頁需檢查：白色句型框內未放 `Mẫu câu` 小標；一般語法頁下方直向排列 `Cách dùng:`、`VD1:`、`VD2:`、`VD3:` 或 `Hội thoại:`，標籤獨立一行、內容放在下一行，不做成左標題右內容兩欄；若使用「文法特殊頁 - 雙區塊」，該頁需為兩個並列結構、兩種用法或 `A vs B` 比較，且符合主句型大卡置中、兩個等寬白底區塊、標題不同標色、標題置中、例句置左與兩卡高度一致規則；若使用「文法特殊頁 - 三區塊」，該頁需為三個並列結構，且符合主句型大卡、`Cách dùng`、三個等寬白底區塊、結構不同標色、結構置中、例句置左與三卡高度一致規則；雙區塊或三區塊若使用編號例句，各區塊需同步使用「標號欄＋句子欄」；標籤底部到例句漢字以 `6px` 為基準；標籤與內容已適度放大且未換行、未超出 PPT 右側安全邊界；所有中文例句已套用漢字對齊規則；例句中的本課語法內容已用黃底紅字突出。
- 一般語法練習若使用一般語法課本題，需逐字核對題型、題幹、挖空句子與挖空位置；除非教師明確要求，不能改成 AB 對話或自編句。功能句練習另需核對課本「功能項目練習」全部情境、題幹、對話、挖空位置與題數，不得刪題或挪作業。
- 練習頁需檢查：已標定 G1-G7 正確頁型；頁面內不重複 `Luyện tập`，改用 1-2 句綠色越南語操作指令；題目由上至下排列；若超出安全區，已優先依題目順序拆頁，不以縮小字體、壓縮行距、縮短題目或刪減答案槽硬塞；AB 對話填空中 `A:` 與 `B:` 已分行；課本題號如 `（1）`、`（2）`、`（3）` 統一為綠底綠字題號標籤；句子換行時第二行首字對齊第一行句子首字，不對齊題號；同一題延續對話句對齊正文首字；`Tình huống（n）：` 情境說明換行時對齊描述正文首字，不對齊情境標籤；填空答案點擊後以紅字帶入空格；不顯示 `Bấm để hiện...` 等點擊提示文字。
- 練習頁互動檢查：每一題資料都必須明確提供題幹、空格／學生作答區與答案或開放作答標記；初始畫面不得直接顯示固定答案。填空題使用 `answer-slot`＋`data-reveal-step`，點擊後才以紅字顯示答案；拼音寫字題顯示拼音與漢字作答空格；開放題顯示學生自行完成的底線。不得只把完整句子直接渲染成練習題。
- 暖身 `Từ gợi ý` 提示詞需以上方拼音、中央漢字、下方 `（越南語）` 呈現。
- 完成後先產出 HTML presenter。
- 每次重新產出 HTML 後，投影片頁面引用的 CSS/JS 需帶版本參數，避免瀏覽器快取舊版樣式或互動腳本。
- HTML presenter 需用網址 hash（如 `#slide-12`）保留目前頁碼；重新整理後主投影片與左側 `Mục lục` 縮圖側欄都要停留在該頁附近，active 縮圖需在側欄可視範圍內。
- HTML presenter 下方工具列採白色膠囊列；Prev、Next、頁碼與 Present 可保留文字，其餘課堂工具用 icon 呈現。
- 畫筆工具需提供下拉選單，至少包含一般畫筆與螢光筆；螢光筆使用半透明粗線，並需可保存、復原與匯出 PDF。
- 圖形工具需提供下拉選單，至少包含圓形、方形、星星、綠色勾與紅色 X；圖形畫在註記 canvas 上，拖曳時需以虛線或淡色預覽目前圖形樣式，放開後才正式畫入；需可保存、復原、清除與匯出 PDF。

## 13. HTML PPT 檔案編號與目錄同步（僅舊產生器路線）

HTML PPT 必須分開管理目錄順序與課程頁碼：

- `deckIndex` 是目錄中的實際 PPT 順序，從 1 開始連續編號。
- `lessonPage` 僅為舊教師審核稿的頁碼，可因刪頁而跳號；課本頁碼另外存入 `textbookPages`，不可由投影片序號推算。
- `fileName` 必須依 `deckIndex` 產生；目錄第 21 張必須是 `slide-21.html`。
- 投影片頁碼依 `deckIndex` 顯示；課本來源與課文資訊依 `textbookPages` 顯示；`lessonPage` 只用於追溯舊稿。

### 13.1 生成步驟

1. 建立已確認的頁面順序清單，明確排除刪除頁。
2. 依清單順序建立 `deckIndex`。
3. 建立新的暫存輸出資料夾，保留目前可用版本；以下步驟均在暫存資料夾完成。
4. 依 `deckIndex` 連續寫入 `slide-01.html`、`slide-02.html` 等檔案。
5. 將實際輸出檔名寫入 `MANIFEST`。
6. 目錄 iframe、標籤、導覽、hash 與 PDF 檔名只從 `MANIFEST`／`deckIndex` 取得。
7. 驗證新版本的目錄與投影片後才切換輸出入口，保留上一版供還原；不得只修改縮圖標籤。內容局部修正只重建受影響頁，頁面增刪才同步完整目錄。

### 13.2 生成資料

```js
{
  deckIndex: 21,
  slideId: "grammar-example-a", // 建立後固定，不隨排序改變
  lessonPage: 22, // 僅追溯舊審核稿
  textbookPages: "13-14", // 範例值，實作時逐頁核對來源
  fileName: "slide-21.html",
  content: pageHtml
}
```
