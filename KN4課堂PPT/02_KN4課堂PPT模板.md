# KN4 課堂 PPT 模板

> 執行順序與共用規格以根目錄 `製作契約.md` 為準；本文件保留 KN2／KN4 各自的課程與頁型內容。

本模板用於每一課 HTML 課堂投影片製作。請依課本實際內容替換 `{{ }}` 欄位。

本文件同時保留舊產生器的 HTML 頁面規格與教材包生成後的 editor 頁型規格。新課或內容變更先以課本建立 `lessonPackage`、逐頁 `sources` 與結構化 `items`，完成來源與教師內容核對後按 editor UI 生成，或使用可選的 `build_course.cjs` 生成 `.slides.json`；editor 只作生成後的可選微調。`.slides.json` 的 `slides` 陣列決定顯示順序，`layoutOverrides` 保存位置、尺寸與樣式修改；內容修改須回寫 `items` 並使該項核對失效。符合 `頁碼`、`檔名`、`投影片畫面文字` 欄位的 Markdown 匯入只會建立保留全部列的待溯源文字草稿，不會重建舊版面、圖片配置、互動或答案狀態。下方標示「僅舊產生器路線」的 presenter、Manifest 與 PDF 註記要求不套用到 editor。

## 六項通用排版規則

**共用主要內容區左右內距**：所有頁型均以 `960 x 540` 為投影片畫布，主要內容區距投影片左、右邊界各 `27px`；頁型專屬卡片、來源與頁碼仍須在此安全區內另行排版。

1. **段落間距**：例句與例句、題目段落與題目段落之間統一使用 `6px`。AB 對話視為同一個例句區塊，不拆成多個獨立排版容器；A/B 只是換行時，不使用段落間距。
2. **同一句內部自動換行**：無超綱標注使用 `line-height: 44px`；含超綱標注且可能換行或實際換行時，外層文字區塊使用 `line-height: 60px`，超綱詞內部行盒固定 `line-height: 42px`。
3. **超綱生詞標注**：採 inline 格式，拼音在漢字上方、越南語在漢字下方；拼音與越南語字級皆為 `9.33px`，拼音相對漢字的排版偏移參考 `-5px`、越南語相對漢字的排版偏移參考 `-4px`；一般漢字與超綱漢字需同基準線／同視覺高度。
4. **編號例句換行對齊**：凡例句、題目或功能句例組使用 `1.`、`2.`、`3.` 等編號時，需採「標號欄＋句子欄」排版；標號獨立固定於左側，句子內容獨立成右側文字欄。若句子自動換行，第二行需對齊句子欄第一個漢字，不可對齊標號。
5. **頁面容量與拆頁**：完成版面後必須以實際渲染結果檢查內容是否超出投影片安全區、頁尾來源或頁碼區。練習頁若超出，解決方案永遠優先採「依題目順序拆成兩頁或多頁」，不得先用縮小字體、壓縮行距、縮短題目或刪減答案槽硬塞同一頁；字級微調只能作為拆頁後的細部排版。拆頁後必須同步更新檔名、Manifest／縮圖清單、總頁數、每頁頁碼，以及對應的教師審核稿與 HTML_PPT 製作稿。
6. **HTML presenter 狀態保留（舊產生器路線）**：`index.html` 需用 `#slide-XX` 保留目前頁碼；重新整理後主投影片需停留在同一頁，左側 `Mục lục` 縮圖側欄也需自動捲動到目前 active 頁縮圖所在位置，不可跳回第一頁。editor 路線依 `.slides.json` 的固定 `id` 與匯出 HTML 的頁面位置保存狀態。

**排版修改後複檢**：每次調整 PPT 排版後，必須重新檢查該頁是否符合通用格式標準，不可只檢查剛修改的局部。通用格式標準至少包含：960 x 540 安全區、主要內容區左右各 `27px` 內距、上方 Banner、左下來源、右下頁碼、段落間距、同一句內部自動換行、超綱生詞格式與漢字對齊、題目／例句換行對齊、該頁型專屬版面規則；練習頁若超出，仍優先拆頁。

## 全局規則

- 投影片說明文字：越南語。
- 中文生詞、例句、句型、課本題目：簡體中文。
- 拼音只放在需要讀音、辨音、提示詞或超綱詞的地方。
- 所有頁型只要出現「例句」，包含生詞頁、語法／句型頁、功能句頁、補充辨析頁與 MỞ RỘNG 例句，都必須套用漢字對齊規則：一般漢字與超綱標注漢字需在同一基準線／同一視覺高度；超綱黃底紅字不得造成漢字上浮或下沉；拼音、越南語標注只能貼附在詞語上下，不得撐高或壓低該行漢字。例句若位於 `Mẫu câu`、`VD1`、`VD2`、`Hội thoại` 等標籤下方，標籤底部到例句漢字以 `6px` 為基準，不論該句是否含超綱標注。實作後需用截圖或 DOM 字框量測確認，不只看 CSS 屬性。
- 第一層：段落間距。所有頁型中，例句與例句之間、題目段落與題目段落之間統一用 `6px`；適用於生詞例句、語法／句型例句、功能句例句、練習題段落與 MỞ RỘNG 例句。AB 對話視為同一個例句區塊，不拆成多個獨立排版容器；A/B 換行不靠段落間距控制，改由第二層 `line-height` 控制。
- 第二層：同一句內部自動換行。單一句子、單一題目或同一組 AB 對話若在同一區塊內自動換行，用 `line-height` 控制行距。無超綱標注時以 `line-height: 44px` 為基準；含超綱標注且可能換行或實際換行時，外層文字區塊用 `line-height: 60px`，超綱詞內部行盒固定 `line-height: 42px`，並保留拼音相對漢字的排版偏移參考 `-5px`、越南語相對漢字的排版偏移參考 `-4px`，避免上行越南語與下行拼音重疊。
- 練習頁若實際渲染後超出投影片安全區、頁尾來源或頁碼區，第一方案永遠是依題目順序拆成兩頁或多頁；G4 可先依該頁型規則採用越南語較小、中文答案較大的分級字級；若仍超出，才拆頁。不可刪題、刪答案或刪減答案槽硬塞同一頁。拆頁後需同步更新檔名、頁碼、總頁數、Manifest、縮圖與對應製作稿／審核稿。
- 編號例句、編號題目或功能句例組若使用 `1.`、`2.`、`3.` 等標號，需拆成「標號欄＋句子欄」；標號欄固定於左側，句子欄從第一個漢字開始。句子自動換行時，第二行對齊句子欄第一個漢字，不對齊標號；若句中有超綱標注，仍同時套用漢字對齊、超綱標注與第二層 `line-height` 規則。
- 所有練習頁的頁內文字說明只放 1-2 句越南語操作指令，文字使用綠色 `#5AACAC`。不得使用 `Cách làm` 作為頁內標題，也不得另放語法名稱、句型名稱或額外語法說明；若需要練習選項，可在操作指令中簡短說明。
- 不放「課堂目標」頁。
- 不放「上課方式」頁。
- 課文處理採「段落循環」：依每課實際課文／對話段數，逐段完成「預習回收 → 該段核心生詞講解 → 該段語法／句型講解 → 對應語法練習」。不預設一定三段課文；每一段課文都完成一輪後，才接功能句學習、團體任務與收尾。
- 不放核心生詞總覽頁。
- 生詞直接講解，1-2 頁一個生詞。
- 生詞例句儘量設計成問句，方便課堂互動。
- 生詞頁左側白色生詞框做成閃卡：正面以拼音＋漢字為主，背面只放兩行資訊：第一行為越南語詞性，第二行為越南語翻譯；不得顯示 `Loại từ`、`Nghĩa` 等欄位標籤。背面兩行需水平、垂直置中，詞性用青綠色 `#5AACAC`，翻譯用深藍色 `#1A3A5A`，兩行上下間距約 `6px`，排版固定為「詞性在上、翻譯在下」的字卡背面樣式。若生詞為離合動詞，需在左側閃卡正面漢字下方加紫色越南語標注 `Động từ ly hợp`；若生詞為成語，需在左側閃卡正面漢字下方加紫色越南語標注 `Thành ngữ`。此類型標注固定放在漢字下方，不移至閃卡背面。
- 生詞頁右側例句、互動問句或 AB 對話中，若出現本頁生詞，必須用黃底紅字突出該生詞；合併多詞頁需分別突出所有本頁生詞；若合成詞在例句中拆開出現，也需突出可辨識的生詞部分。
- 生詞頁右側例句採固定排版基準：右側卡片左內距 `10px`、右內距 `10px`、卡片寬度 `546px`、文字可用寬度 `526px`、卡片右側邊界到投影片邊界 `27px`、右側卡片左側邊界到左側卡片右側邊界 `10px`；例句主字級 `22pt`、一般同句換行 `line-height: 44px`、段落間距依第一層通用規則用 `6px`；含超綱標注且可能換行或實際換行時，依第二層規則使用外層 `line-height: 60px`、超綱詞內部 `line-height: 42px`；超綱標注的拼音與越南語字級 `9.33px`；拼音相對漢字的排版偏移參考 `-5px`，越南語相對漢字的排版偏移參考 `-4px`；以 `22pt` + Noto Sans SC 渲染後，漢字高度以未縮放畫布的實際字形為準，`42px` 僅為超綱詞內部行盒高度。以上需用截圖或 DOM 字框量測，不只看 CSS 屬性。
- 生詞頁 AB 例句整體只放在一個獨立內容區塊內，不拆成多個 `content-card` 或多個獨立排版容器；A/B 可分行或自然換行，但同一段對話需共用同一組字級、段落間距與第二層 `line-height` 規則。
- 補充辨析頁中的越南語說明短句，句首第一個字母必須大寫。
- 圖片不是必須，但可用圖片、icon 或簡潔視覺元素優化版面；封面、生詞頁、功能句文化頁、下课页、情境練習頁優先考慮。
- 生詞頁補圖不是預設必做；進入圖片生成前必須先檢查版面空間與教學必要性。優先補具體名詞、具體物品、明確動作或生活／校園場景詞；抽象詞、語法性強的詞、功能詞或已可由例句清楚理解的詞，原則上不補圖。生詞頁右側例句或 AB 對話下方可用高度約 `140px` 以上，才可考慮放約 `180px x 110px` 的小型輔助圖；可用高度約 `90px` 到 `120px` 時原則上不補，除非教師指定。不得為了補圖縮小例句、壓縮行距、破壞超綱標注或造成例句不必要換行。
- 圖片生成工具規則：正式教材圖片只使用 ChatGPT 生成；不得改用其他自動生圖工具。Codex 內建 `image_gen` 不作為預設生圖方式，只有在教師／使用者明確核可使用 `image_gen` 時，才可操作；未核可前，即使圖片需求表與 prompt 已確認，也不得使用 `image_gen` 生圖。
- 使用 ChatGPT 生成教材圖片時，需依 `05_KN4圖片生成與嵌入流程.md` 先整理圖片需求表，再寫 prompt、生圖、下載、裁切、嵌入與 QA。
- HTML/CSS 暫時畫出的視覺元素、暫用 SVG、placeholder 圖與生詞頁可補強的 icon，都需列入圖片需求表；例如需用生成圖取代 `charging-phone.svg` 時，需在表中明確標記。
- 圖片中的文字、字母、數字、標籤或字幕依教師指定與圖片需求表為準；未指定時，prompt 不主動加入可讀文字。頁面教學文字仍優先由 HTML 投影片另外排版。
- 封面圖可用放大裁切與 `object-position` 減少圖片內空白，但不得壓到左側標題區。
- 生詞頁圖片放在右側例句或 AB 對話下方空白處，並以閃卡右邊界到 PPT 右側安全邊界之間的可用區域置中；補圖前先確認右側下方可用高度與教學必要性，約 `140px` 以上才可考慮小圖，約 `90px` 到 `120px` 原則上不補；圖片可放大，但不得遮住文字、壓頁尾、造成例句不必要換行、縮小字級、壓縮行距或破壞超綱標注。
- 封面不顯示 `45 phút x 3 buổi` 等課堂總時長；不重複放置課程名稱與 Lesson 資訊，若已放 `KN4 - Bài {{lesson_number}}`，不可再放 `Kỹ năng Nói 4 - Bài {{lesson_number}}`。
- 封面採左文右圖時，文字欄與圖片欄必須固定分區並保留安全距離；標題以 PPT 上下邊界垂直置中，並在 PPT 左邊界到右圖左框的可用區域內水平置中。標題過長需縮小字體，可從逗號處分兩行，避免碰到右側圖片或視覺元素。
- 暖身頁的快速回答題目使用中文簡體；上方小 Banner 標題使用越南語 `Khởi động`，不可使用中文「暖身活動」；問題區不使用白底框；問句字級需依長度縮小，儘量一行呈現但不得超出版面；提示句型與提示生詞放在問句下方，採橫式排列，文字需自動縮小避免擠壓。
- 暖身頁 `Mẫu câu` 與 `Từ gợi ý` 區塊標籤需使用同一字體、字級、字重與大小寫樣式。
- 暖身頁提示句型若需要留空，不使用中文省略號 `……`，改用 baseline 位置的 `......`。
- 暖身頁 `Từ gợi ý` 的提示詞呈現為：漢字上方放拼音，漢字下方放 `（越南語）` 翻譯。
- 「想一想、说一说」一個問題一頁，每頁必放提示生詞與提示句型。
- 預習回收頁上方小 Banner 顯示 `Ôn phần chuẩn bị`；問句卡內不可再重複放 `Ôn phần chuẩn bị`。
- 預習回收頁問句上方需顯示 `课文：P{{page_range}}《{{text_title}}》`；課文標題必須加書名號《》，不可只放裸標題。
- 預習回收頁的課文資訊與問題卡需依 PPT 上下左右安全邊界整體置中；問題儘量一行呈現，不得超出版面。
- 預習回收頁問題改為閃卡：正面是問題，背面只放參考答案句子，不顯示 `答案` 標籤；點擊工具列下一步或卡片本身需有翻牌效果。
- 預習回收頁閃卡背面的答案必須是完整中文句子，水平左對齊、垂直置中在白色閃卡框中；無超綱標注時答案文字換行使用 `line-height: 44px`；含超綱標注且可能換行時，外層文字使用 `line-height: 60px`、超綱詞內部使用 `line-height: 42px`；不使用片語式答案或教師備註式答案方向；若答案包含多個理由或步驟，採一個理由／步驟一行；優先利用投影片上半部安排課文資訊與閃卡，保留可讀字級，再將提示區配置於下方，避免重疊；例如：`办银行卡需要带护照、学生证或者其他有效证件。`
- 預習回收頁也必須做超綱生詞交叉檢查；範圍包含題目、提示句型、提示詞與背面答案。若保留超綱詞，投影片呈現必須為漢字上方拼音、漢字下方 `（越南語）` 翻譯。
- 超綱標注以實際超綱詞素為單位；例如 `利和弊` 只標注 `利`、`弊`，不連帶標注中間的 `和`。
- 預習回收頁若提示句型或提示詞較多，需優先利用 Banner 下方的上方安全空間排列，避免內容全部垂直置中而留下不必要的上方空白；所有提示生詞均需在漢字上方放拼音、下方放 `（越南語）` 翻譯。
- 一般語法練習採「作業先保留、PPT 後安排」；先建立完整題目池並標記回家作業保留題，再安排未保留的一般語法課本題。詞語練習一、二、三不自動製作成 PPT 練習頁；只有教師明確指定時，才可列入課堂 PPT 結構。詞語可繼續用於生詞講解、預習回收或其他已指定的課堂活動。一般練習頁預設 3-5 個完整題目／情境／對話區塊；G4 題數依課本或教師指定內容決定，不因附圖範例為四張卡片而補題；不足 3 題時才補同一題型、同一語法的自編題，並標記 `自編補足` 與唯一 ID。
- 每一道已選入 PPT 的一般語法／功能句課本練習題都需建立唯一題目編號，例如 `KN4-L{{lesson_number}}-G{{grammar_number}}-P{{textbook_page}}-Q{{question_number}}`，並記錄課本頁碼、題號、完整題幹、挖空位置與答案。
- 回家作業製作時，必須讀取 PPT 題目登記表，排除已使用題目及高度相似改寫題；若教師指定同題重複，需明確標記為「教師指定重複」。
- 語法練習採「一個語法一組練習（可依容量拆成連續頁）」，練習頁需緊接在對應語法講解頁後；不同語法不可合併成同一頁綜合練習，除非教師明確要求。
- 語法／功能句練習若使用課本題，題型與挖空句子必須完全按照課本；不可擅自改成 AB 對話、改寫題幹或改變挖空位置，除非教師明確要求口說化改編。
- 自製或教師要求改寫的語法練習題需避開前一頁語法例句與課本課文原句的重複或高度相似題；不可只替換少量詞語、人物、時間或數字。可練同一語法結構，但情境、詞彙、動作或句意需明顯不同。若教師指定使用課本原題，則以完整保留課本題為優先。
- 若 AB 對話會造成語境重複或不自然，可在教師要求下改為不超過三句的情境題；同一頁若改為情境題，該頁題目須統一使用情境題型，並以課本原句為主，只補充必要情境、保留原句挖空位置，不任意改寫原句。
- 練習頁上方 Banner 若已顯示 `Luyện tập`，頁面內不可再重複顯示 `Luyện tập`；頁內只放 1-2 句綠色越南語操作指令，不放 `Cách làm`、語法名稱或額外語法說明。填空題題目需由上至下排列，答案以點擊動畫用紅字帶入空格；不顯示 `Bấm để hiện...` 等點擊提示文字。AB 對話填空中 `A:` 與 `B:` 必須分行，不可接在同一行。課本題號如 `（1）`、`（2）`、`（3）` 需統一做成綠底綠字題號標籤；若 `Tình huống（n）：` 已作為情境題號，作答句前不可再重複放 `(1)` 等題號；情境題的題目／作答句統一左對齊，不因重複題號預留左側縮排；若句子換行，第二行首字需對齊第一行句子首字，不對齊題號；同一題的延續對話句也需對齊該題正文首字；`Tình huống（n）：` 情境說明若換行，第二行需對齊描述正文首字，不對齊情境標籤。
- Mẫu câu／語法例句製作前，必須先查找課本對應的語法區塊、課文／對話原文與「读一读、试一试」，不得只憑記憶或直接自行造句。
- VD1 優先使用課文或對話中的原句；VD2 使用同一語法在「读一读、试一试」中的第一個完整例句，通常是第（1）句。完整例句是指沒有挖空、可直接朗讀的句子；原句的文字、標點與語序必須完整保留。
- 若「读一读、试一试」整個對應區塊中沒有完整例句，才允許自行造句；自編例句必須符合該語法、使用本課可用詞彙，並在教師審核稿中註明為「自編例句」，經確認後才可製作 PPT。
- 語法例句的來源、課本頁碼、區塊／題號與 VD1／VD2 類型，必須在教師審核稿中記錄；語法標記只改變顯示樣式，不得改變課本原句內容。
- 語法講解若使用單句例句，放兩個單句；若使用 AB 對話，只放一個對話即可。
- 語法例句中的標點不可被誤判為新例句；同一句例句需保留在同一內容區塊。
- 語法講解頁的白色句型框內只放句型，不再放 `Mẫu câu` 小標；一般語法頁下方依序直向排列 `Cách dùng:`、`VD1:`、`VD2:`、`VD3:` 或 `Hội thoại:`，標籤獨立一行、內容放在下一行，不做成左標題右內容兩欄。標籤與內容可適度放大方便閱讀，必要時自動微縮，但以不超過 PPT 右側安全邊界為準。例句中的本課語法內容需用黃底紅字突出。若有兩個並列結構或 `vs`／比較型語法，使用「文法特殊頁 - 雙區塊」；若同一語法有三個並列結構，可使用「文法特殊頁 - 三區塊」。
- 功能句採三頁結構：第 1 頁為功能句說明頁，一頁只放一個功能項目，採左 `Chức năng`、右 `MẪU CÂU` 分欄並只放課本功能句，左側功能名稱使用中文；第 2 頁為對應句型例句頁，集中呈現該功能的實用例句；第 3 頁為功能句練習頁，必須完整保留課本「功能項目練習」的情境、題幹、對話、挖空位置與題數。功能句練習不套用一般語法的 3-5 題或作業先保留規則；若內容過多，優先依課本順序拆頁，不刪題、不簡化。回家作業另以同一功能改寫新題，使用獨立作業題目 ID。若教師指定例句頁採單欄直排，則 `Chức năng` 在上、例句在下，例句由上至下排列，不使用左右雙欄；指定例句頁中的功能句型套用生詞／語法標記（黃底紅字）。未被指定的例句頁沿用原有版型。功能名稱需單行呈現，若字體過大導致換行，需自動縮小到不換行且不超出白框。功能句說明頁需先標出可套用的句型／語塊重點；若尚未確認重點，不得進入 HTML_PPT 製作稿或 HTML PPT 製作。
- 非疑問句以 `吧` 結尾時，句末標點用 `！`；疑問句或反問句則保留 `？`。
- 功能句練習頁上方只放 1-2 句綠色越南語操作指令，例如 `Hoàn thành hội thoại.`；不使用 `Cách làm`，也不放功能／語法名稱標籤；題目前需加入課本中的該題情境說明。功能句練習須依課本原有題數完整呈現，不足或超過一般語法的 3-5 題標準都不需補題或刪題；若練習內容超出安全區，優先拆成一題一頁或兩題一頁，不以縮小字體硬塞。
- 功能句練習必須完整參照課本「功能項目練習」：保留課本完整情境、題幹、對話內容、挖空位置與題數，不得為了版面或簡化教學而刪除內容；若內容超出安全區，優先拆頁，不以縮小字體、壓縮行距、縮短題目或刪減答案槽硬塞。拆頁後依序編排並同步更新總頁數與頁碼。
- 自製或教師要求重寫的功能句練習，需依前一功能句說明頁或功能句例句頁已標出的句型／語塊重點設計新情境，不可直接把前頁例句挖空後填回答案；可用完成對話、根據情況造句、完成句子等題型，但同頁以一種題型為主，且需避開前頁例句與課文原句的高度相似。
- 功能句練習若只有一個情境／一段對話，只能算一題；題號只放在第一句作答句前，不可把每一句對話自動編成不同題號。
- 功能句若補充文化／歷史快問頁，頁型可用 `Culture`，標題使用越南語 `Văn hoá / lịch sử`；上方問題需水平置中，例：`Nên giới thiệu ai trước?`；問題下方左右兩區塊呈現兩個人／群體，每區塊需有文字與對應圖像。
- 教師內容核對後依入口處理：新課或內容變更先由教材包與 `items` 整理，按 editor UI 生成或用可選的 `build_course.cjs` 生成 `.slides.json`，再可用 editor 整理已核可內容；只改位置、尺寸與樣式時保存到 `layoutOverrides`。舊產生器路線才建立 `HTML_PPT製作稿` 再生成 HTML。符合 `頁碼`、`檔名`、`投影片畫面文字` 欄位的 Markdown 匯入 editor 只算待溯源文字草稿，須補齊來源、正反面、頁型、圖片、答案與核對，未核對前不得正式放映或匯出。
- `HTML_PPT製作稿` 不重新改課堂架構，只把已通過的頁面轉成 HTML 製作欄位：檔名、頁型、畫面文字、互動、動畫、素材需求、教師備註。
- 舊產生器路線只參考 `ai-teaching-material-system-main` 的 HTML PPT 格式、視覺風格與工具欄；不得參考或套用其中的課程架構、學生程度、教學流程與活動設計。
- HTML presenter 下方工具列採白色膠囊列；Prev、Next、頁碼與 Present 可保留文字，其餘課堂工具以 icon 顯示。
- 畫筆工具需提供下拉選單，至少包含一般畫筆與螢光筆；螢光筆使用半透明粗線，能和手寫筆記一起保留、復原與匯出 PDF。
- 圖形工具需提供下拉選單，至少包含圓形、方形、星星、綠色勾與紅色 X；圖形畫在註記 canvas 上，拖曳時需以虛線或淡色預覽目前圖形樣式，放開後才正式畫入；需可復原、清除並隨單頁 PDF 匯出。
- 橡皮擦工具需提供下拉選單，至少包含橡皮擦與刪除物件；刪除物件用於刪除文字註記等獨立物件，並需可復原。
- Present 模式後仍需保留下方工具列；工具列縮小為固定小比例並鎖定在畫面下方，不遮擋主要投影片內容。
- HTML presenter 必須提供單頁 `下載PDF` icon 功能；點擊後下載目前頁面，並包含當頁的手寫筆記、文字註記與已顯示的點擊答案狀態。
- HTML 投影片重新產出時，投影片頁面引用的 CSS/JS 必須帶版本參數，避免瀏覽器快取舊版樣式或互動腳本。
- HTML presenter 需用網址 hash（如 `#slide-12`）保留目前頁碼；重新整理後主投影片與左側 `Mục lục` 縮圖側欄都要停留在該頁附近，active 縮圖需在側欄可視範圍內。
- 每頁左下角灰色來源文字顯示課本頁碼，格式為 `Sách giáo khoa P{{page}}` 或 `Sách giáo khoa P{{start}}~P{{end}}`；不得顯示 `課文一`、`課文二`、`課文三` 等內部分類。
- 教師審核稿最後必須做超綱生詞交叉檢查；範圍包含學生會看到、說出、填出或錄出的所有中文內容。
- 若不得已保留超綱詞，投影片上必須在漢字上方加拼音，漢字下方加 `（越南語）` 翻譯；不得只用旁註或列表注記；超綱詞不套用生詞黃底紅字，除非該詞本身就是本頁教學生詞。

## 圖片版面與生成規則

完整圖片生成、下載、裁切、嵌入與 QA 流程見 `05_KN4圖片生成與嵌入流程.md`。本模板只保留頁面版面規則與 prompt 基本約束。

### 圖片需求

每課若需要圖片，需先整理圖片需求表，至少包含頁碼、檔名、頁型、用途、視覺內容、生成方式、比例、放置位置與 QA 注意事項。

圖片製作狀態必須依序記錄：`待審核圖片需求` → `待確認生圖` → `待審核裁切素材` → `可嵌入 PPT` → `已完成 QA`。教師未確認圖片需求表與 Prompt 前，不得生圖；即使已確認 Prompt，未取得教師明確同意前，也不得操作 ChatGPT；正式教材圖片只使用 ChatGPT 生成，不改用其他自動生圖工具；Codex 內建 `image_gen` 只有在教師／使用者明確核可時才可作為例外操作；教師未確認裁切素材前，不得嵌入 PPT。

需列入圖片需求表的項目：

- 封面圖、下课页、情境圖。
- 生詞頁 `Từ vựng` 小圖或 icon。
- 功能句、文化快問、補充辨析頁的人物或情境圖。
- HTML/CSS 暫時畫出的視覺元素。
- 暫用 SVG、placeholder 圖，例如 `charging-phone.svg`。

### 版面規則

- 封面圖可使用放大裁切與 `object-position` 減少空白；左側標題區優先，不得與圖片重疊。
- 生詞頁圖片放在右側例句或 AB 對話下方空白處；水平位置以閃卡右邊界到 PPT 右側安全邊界之間的可用區域置中。
- 生詞頁圖片可放大，但不得遮住例句、對話、頁碼、來源文字或工具列；也不得因圖片占位造成例句不必要換行。
- 文化、功能句與對照頁的圖片需和文字選項位置對應；左右對照圖的尺寸與視覺權重需一致。

### Prompt 基本約束

- 每個 prompt 最多 16 張圖；超過 16 張必須拆批。
- Contact sheet 需明確寫出排列方式與 row-major order。
- 圖片中的文字、字母、數字、標籤或字幕依教師指定與圖片需求表為準；未指定時，prompt 不主動加入可讀文字。
- 中文、越南語、拼音、頁碼等文字優先由 HTML 投影片排版；若教師指定圖片內文字，需在需求表與 prompt 中寫清楚。
- 同一課圖片需保持一致教材風格：柔和線稿、低飽和色、乾淨背景、低對比陰影，適合課堂投影。

## HTML PPT 編號與頁碼標準（僅舊產生器路線）

HTML PPT 必須分開管理目錄順序與課程／課本頁碼，不得以課本頁碼直接作為輸出檔名。

editor 路線不使用本節的 HTML 檔名、Manifest 或 iframe 規則；其顯示順序取教材包生成的 `.slides.json` `slides` 陣列，頁面以固定 `id` 識別，來源由 `sources`／`items` 追溯。需要課本頁碼時，逐頁填入教材來源並在重新開啟與匯出檢查時核對；位置、尺寸與樣式由 `layoutOverrides` 保存。

| 欄位 | 定義 | 範例 |
|---|---|---|
| `deckIndex` | 目錄中的實際 PPT 順序，從 1 開始連續編號 | 第 21 張 |
| `lessonPage` | 原始課程或教師審核稿頁碼，可因刪頁而跳號 | P22 |
| `fileName` | 依 `deckIndex` 產生的 HTML 檔名 | `slide-21.html` |
| 課本來源 | 投影片左下角顯示的課本頁碼範圍 | `Sách giáo khoa P29~P30` |

### 命名與目錄規則

- `slide-21.html` 永遠代表目錄第 21 張 PPT。
- 刪除頁面後，後續檔案必須依目錄順序重新連續命名。
- `MANIFEST`、縮圖 iframe、下方標籤、導覽、URL hash 與 PDF 檔名全部使用 `deckIndex`。
- 投影片頁碼使用 `deckIndex`；課本頁碼、課文來源使用獨立的 `textbookPages`；`lessonPage` 只用於追溯舊審核稿。
- 目錄左側編號、iframe 檔名與下方標籤必須一致，例如 `21`、`slide-21.html`、`slide-21`。
- 生成至新的暫存輸出資料夾；驗證通過後才切換輸出入口，保留上一版。不得先清除可用版本；舊檔清理由上一版 Manifest 限定範圍。

### 生成資料格式

```js
{
  deckIndex: 21,
  slideId: "grammar-example-a", // 建立後固定，不隨排序改變
  lessonPage: 22, // 僅追溯舊審核稿
  textbookPages: "13-14", // 範例值，實作時逐頁核對來源
  fileName: "slide-21.html",
  content: pageHtml
}
```

`deckIndex` 控制輸出與導覽；`textbookPages` 控制課本頁碼與教材來源，`lessonPage` 只追溯舊稿。

### 生成後檢查

- 輸出檔案從 `slide-01.html` 連續至最後一頁，沒有跳號或舊檔案。
- `MANIFEST` 數量等於輸出 HTML 數量。
- `MANIFEST[n-1]` 等於 `slide-{{n}}.html`。
- 刪頁位置前後至少檢查兩頁，確認目錄順序、檔名與內容同步。
- 實際點選目錄第 21 張，確認載入的檔案也是 `slide-21.html`。
- 檔名改變後，投影片內的課本頁碼仍然正確。
