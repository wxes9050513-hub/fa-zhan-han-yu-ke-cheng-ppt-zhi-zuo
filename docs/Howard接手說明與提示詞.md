## 更新與啟動

先下載目前課程備份、保留本機尚未提交的教材修改。由 repository 擁有者審閱並合併 [更新 PR](https://github.com/wxes9050513-hub/fa-zhan-han-yu-ke-cheng-ppt-zhi-zuo/pull/1)。合併後在乾淨的 repository 目錄執行：

```sh
git switch main
git pull --ff-only origin main
```

遇到分歧或衝突先停止並保留本機修改，不要強制重設。尚未合併 PR 時，可先在本機建立測試分支：

```sh
git fetch origin pull/1/head:howard-workflow-review
git switch howard-workflow-review
```

若分支已存在，不強制覆蓋，改用另一個新的分支名稱。雙擊最外層 index.html，再從「開啟課程」讀取備份；新課使用「教材與課程資料庫」。教材抽取工具只整理逐頁原文，items 仍需 AI／教師整理，不能把空資料庫當成已完成教案。教材包格式與操作見 [教材包格式](教材包格式.md) 及 [編輯器使用說明](../editor/使用說明.md)。
