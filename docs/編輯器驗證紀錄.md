2026-09-07，本倉庫新增 editor/，解決教材包生成後的小幅位置、文字與圖片調整仍需反覆生成的問題。此紀錄分開說明編輯器／教材流程功能測試與真實教材內容核對；editor 功能通過不代表自動生成內容已獲教師核可。

- Node 標準庫模型檢查：資料可往返、ID 穩定；拒絕重複 ID、不安全 ID、錯誤型別、無限座標、超出畫布、不支援物件及不安全圖片網址。
- Python 文件檢查器 8 項測試通過。
- 桌面 Chromium：拖曳、右下角縮放、雙擊直接改字、右側文字欄、復原／重做及重新整理保留修改。
- 圖片嵌入後重新整理仍存在；鎖定位置會停用座標欄位。
- 模擬最新修改超過保存容量，確認較早的存檔完成不會清除「尚未保存」提示。
- 同課程兩分頁同時編輯：舊分頁停止自動保存，重新整理確認新分頁內容未被蓋掉。
- 下載 JSON → 開啟 JSON 保留修改；最近課程可重新開啟。新增副本與上下移動投影片可復原／重做。
- 交付 ZIP 重新解壓後，在封鎖 HTTP／HTTPS 的 Chromium 中開啟、載入隨附 JSON 示範與翻牌均通過。
- 根目錄 index.html 以 file:// 直接開啟，修改名稱後重新整理仍保留；不用本機伺服器也可工作。
- 匯出單一 HTML 以 file:// 開啟，翻牌可切換；教師備註不輸出；含 script 標籤的文字不會執行。
- 放映視窗、全螢幕及翻牌互動通過。
- 五份現有 Markdown 分別匯入 50、57、60、60、67 頁，沒有因重複舊編號刪掉列。原文保存在教師備註。
- Chromium PDF：兩頁課程輸出兩頁 PDF，頁面 720 × 404.88 pt，沒有多出空白頁。

## 界線與剩餘工作

### 同日教材流程整合回歸

- Python 共 10 項測試通過，包含逐頁文字、頁碼數量不符與空白文字拒絕；Node 模型與教材流程測試均通過。
- Chromium 匯入未核對示範教材包：阻擋生成；對照來源頁、勾選教師核對後成功生成。
- 從投影片修改答案，資料庫立即顯示新答案並阻擋匯出；重新核對與生成後，手動設定的 x=40、w=880 保留。重新整理和下載 JSON 重開亦保留。
- 從資料庫新增補充練習，填入教學目標、來源、越南語指令及參考答案，核對後生成兩頁。
- 修改原教材頁文字後，受影響項目須重新核對，未核對時阻擋生成。
- 最新匯出 HTML 離線開啟、點擊答案切換通過；不包含 lessonPackage、reviewedText、fingerprint 或測試教材原文。
- 編輯器列印入口生成兩頁 PDF，720 × 404.88 pt；PDF 抽取工具可抽回兩頁文字，輸出仍為未核對來源、items 為空。
- build_course.cjs 實際讀取示範教材包與舊課程檔，成功重建兩頁。以上只使用功能示範，核對動作不代表真實課本獲得教師核可。
- 最新 ZIP 解壓後以 file://、封鎖 HTTP／HTTPS 開啟，載入兩頁備份並通過正式匯出檢查。另以超長背面答案確認溢出會阻擋正式匯出。

前節 ZIP／兩分頁等測試來自較早的編輯器版本；本輪重新測試教材生成、回寫、版本失效、備份重開與正式輸出。自動檢查不能證明實際教材語意與程度正確。

Markdown 匯入只接受含 `頁碼`、`檔名`、`投影片畫面文字` 欄位的製作表，僅擷取標記文字，沒有套用專用頁型、帶入所有圖片或自動分類題目與答案；它是待溯源草稿，不是正式教材入口。新課或內容變更仍須先讀教材、建立 `lessonPackage`／逐頁 `sources`／`items`、完成教師核對，再生成 JSON。內容修改要回寫 `items` 並使該項核對失效，版面修改要保留在 `layoutOverrides`；未核對資料不能正式放映或匯出，但可下載備份。KN4 L2／L3 的內容順序疑點仍需對照課本；保留所有列不代表解決教材疑點。既有製作稿中的 QA 勾選不作為本版驗證證據。

本版沒有 .pptx／任意 HTML 匯入、富文字拼音定位、手寫註記、雲端同步或多人協作。PDF 只有正面狀態。尚未驗證所有真實教材輸入、Safari、Firefox、實體投影設備、所有實際教材正反面排版或完整課堂使用；掃描 PDF 的文字仍需外部 OCR，不能由空結果推測。未量測朋友備課時間，不能宣稱已從數天降至特定分鐘數。

## 後續修改的回歸檢查

執行 python3 -m unittest discover -s scripts -p 'test_*.py' 與 node scripts/test_editor_model.cjs。若修改編輯器，再於瀏覽器完成：拖曳文字 → 雙擊改字 → 復原／重做 → 加圖 → 等待已儲存 → 重新整理 → 下載課程檔 → 重開 → 匯出 HTML → 離線放映並點翻牌。修改存檔時另做兩分頁衝突；修改列印時核對 PDF 頁數。CI 僅執行程式／模型檢查，不冒充瀏覽器測試。
