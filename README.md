# 發展漢語課程 PPT 製作

這個專案保存 KN2／KN4 課程內容、教師審核稿與 HTML 投影片製作規格。此處 PPT 指 HTML 課堂投影片。

## 正式入口：先從教材建立課程

新課或內容變更一律先讀本課課本與教師核可資料，再建立或更新教材包與本課結構化內容資料。流程是：讀教材 → 建立教材包／`lessonPackage`、`sources`、`items` → 人工核對 → 按 editor 的「核對完成，生成 PPT」或使用可選的 `build_course.cjs` 生成可編輯 `.slides.json` → 視需要手動微調。AI 或教師整理出的內容仍須經教師核對，不能把自動生成當成核可。

`scripts/prepare_lesson_package.py` 可讀取文字檔與有文字層的原生 PDF；掃描 PDF 沒有可讀文字時，必須先取得 OCR 結果，不能臆造或把空文字當成課本內容。教材包的 `sources` 逐頁保留課本文字與來源；`items` 保存穩定 ID、題型、目標、教材／教師補充來源、正面、答案、超綱標注與核對狀態。程式可檢查來源、必填欄位、題型、正反面格式、版本及安全區等結構條件；語意、程度與教學品質仍由教師判定。

教材包完成來源與核對後即可進入正式 editor 流程。下載本倉庫 ZIP 並解壓縮，使用桌面 Chrome 或 Edge 開啟根目錄 **index.html**；UI 會直接完成教材整理與生成，若只做已生成 JSON 的離線編輯、放映或匯出時不需要 Node、Python 或舊產生器。命令列批次參數與格式見 [教材包格式](docs/教材包格式.md)，完整 UI 操作見 [編輯器使用說明](editor/使用說明.md)。

1. 新課按「新課程」進入「教材與課程資料庫」，先讀取／匯入教材、保存原頁碼與文字、整理 `items` 並逐項核對；也可用 `build_course.cjs` 產生的 `.slides.json` 開始。未完成教材與核對前，投影片畫布與格式工具保持鎖定。
2. 生成後才可拖曳文字、圖片與卡片；位置、尺寸與樣式修改記在 `layoutOverrides`，重建時保留。
3. 若改題目、答案、指令或其他課程內容，必須回寫對應 `items`／來源，該項核對狀態隨即失效，重新核對後再生成或正式交付；不能只改投影片物件。
4. 按「下載課程檔」保存可繼續編輯的 `.slides.json`，圖片一併保存在檔案內。正式放映、匯出與列印前的交付檢查會量測每頁正面及翻牌／答案背面是否溢出；通過來源、內容與版面檢查後才按「開始放映」或「匯出簡報」；「列印 / PDF」保存靜態正面頁面。

瀏覽器會自動保存最近的課程，但清除瀏覽器資料、更換電腦或移動編輯器路徑可能使資料無法找到。**每次完成修改都下載課程檔備份。**

舊 `.slides.json`、HTML_PPT 製作稿及符合 `頁碼`、`檔名`、`投影片畫面文字` 欄位的 Markdown 匯入，只作待溯源／遷移草稿：保留全部列與原文備註，不重建舊版面、圖片配置、互動或答案，也不能在未完成來源與核對前正式放映或匯出。草稿始終可以下載備份。這不是 PowerPoint `.pptx` 或任意 HTML 的匯入器。

## 製作或修改一課

先讀 [製作契約](製作契約.md)、本課課本／教材包與教師核可紀錄，再讀所屬課程的 01 架構與 02 模板；既有單頁修正只讀受影響頁與頁型。AI 助理從 [AGENTS.md](AGENTS.md) 進入，不套用參考專案的個人偏好。舊 `HTML_PPT製作稿.md` 只在沿用舊產生器或整理待溯源資料時使用。

在專案根目錄執行（需要 Python 3，無第三方套件）：

```bash
python3 scripts/check_slide_draft.py "KN2課堂PPT/L2_晚上早点儿睡/KỸ NĂNG NÓI 2-L2_HTML_PPT製作稿.md"
python3 -m unittest discover -s scripts -p 'test_*.py'
```

新課或內容變更可在 editor 的教材資料庫直接讀取／貼上教材並生成；需要批次處理時，再用 `scripts/prepare_lesson_package.py` 整理文字／原生 PDF，或用 `scripts/build_course.cjs` 從已核對教材包生成 `.slides.json`。實際參數依 [教材包格式](docs/教材包格式.md) 與本課紀錄，不把舊製作稿檢查器當成教材包或教師核可。生成後的 editor 微調仍須依 `lessonPackage`、`sources`、`items`、`layoutOverrides` 的回寫規則保存。

檢查器會找重複／跳號、輸出檔名、缺少欄位與總頁數衝突，遇到不支援或不完整的製作表會報錯。加 `--json` 可輸出帶來源雜湊的結果；加 `--slides-dir "實際slides資料夾"` 可另核對輸出缺檔與殘留檔。這項檢查不讀取 presenter Manifest，仍須另外核對導覽。它不會改稿、不產生 HTML，也不驗證課本內容或排版。

目前 KN4 L2／L3 仍有需人工核對的編號與內容順序，預檢會阻擋它們；見 [診斷與修正紀錄](docs/診斷與修正紀錄.md)。不要為取得 PASS 而刪題或忽略錯誤。

## 本機 HTML 系統

朋友原有的 `ai-teaching-material-system-main/` 是另一個本機專案，沒有放在這個 Git 倉庫。既有產生器路線仍可使用朋友本機的版本；本倉庫的新編輯器不依賴它。[原始系統](https://github.com/ssyan110/ai-teaching-material-system) 只供程式參考，不能假設與本機修改版相同。

第一次在新電腦生成前，確認本機系統路徑、版本、實際建置命令及一課可開啟的輸出；把非敏感資訊記在本課製作稿。尚未確認時，仍可進行內容與文件預檢，不宣稱已生成可上課投影片。不要直接用上游覆蓋朋友的產生器。
